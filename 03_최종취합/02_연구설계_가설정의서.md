## 1. 연구 체계도 (Framework Overview — 축소안 기준)

본 연구는 불필요하게 넓은 범위를 걷어내고, 학위논문의 핵심 기여를 가장 선명하게 입증할 수 있는 **3개 정예 모듈(진단 $\to$ 매핑 $\to$ 치료)**로 압축하여 실행됩니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   [정예화된 연구 파이프라인 구조 (축소안)]             │
├────────────────────────────────────────────────────────────────────────┤
│  [모듈 1. 가상 통제 진단] (In Vitro Experiment)                         │
│  • FinStressTS 핵심 3대 메커니즘 독립 조작 (Ceteris Paribus 통제)       │
│    - 축 1: 변동성 군집 (GARCH)                                          │
│    - 축 2: 두꺼운 꼬리 (Fat Tails, Student-t)                           │
│    - 축 3: 체제전환 (Markov Regime Switching)                           │
│    *(HAR 다중스케일, 호크스 점프, 영과잉 3축은 '여력 시 확장 부록'으로 분리) │
│  • 대상 모델: 주력 2대 TSFM                                            │
│    - 모델 1: Chronos-Base (Amazon, 200M) — 이산 토큰화 언어모델 대표   │
│    - 모델 2: Moirai-Base (Salesforce, 91M) — 패치 및 혼합 모수분포 대표 │
│    *(TimesFM, TTM은 여력 시 보조 비교군)*                               │
│  • 측정 지표: 불편추정 CRPS, PIT U자형 왜곡, 90% 명목 커버리지 붕괴선  │
├────────────────────────────────────────────────────────────────────────┤
│  [모듈 2. 실측 시장 대조 매핑] (In Vivo Validation)                     │
│  • 미국 대표 5종목 (AAPL, AMZN, GOOG, JPM, META) 중심 매핑             │
│  • 한국 시장 (KOSPI 200) 대표 1~2개 자산으로 보조 검증                  │
│  • 실측 자산의 stylized facts(꼬리지수, 변동성지속성, 체제전환빈도) 산출│

├────────────────────────────────────────────────────────────────────────┤
│  [모듈 3. 저비용 사후 적응 치료] (Calibration Therapy)                  │
│  • 모델 재학습(파인튜닝) 0원: 동결된(Frozen) TSFM 백본 그대로 유지      │
│  • 적응형 콘포멀 사후 보정(Adaptive Conformal Calibration) 투입        │
│  • 90% 신뢰구간 복원율 및 VaR(Value at Risk) 리스크 관리 유효성 검증   │

```

## 2. 3대 핵심 연구 가설의 수리적 정의 및 쉬운 해설

### 가설 1 (H1. 비정상 체제전환 치명성 가설 — 핵심 3대 축 대상)
* **수리적 정의**:
  주어진 시계열 파운데이션 모델 $\mathcal{M} \in \{\text{Chronos}, \text{Moirai}\}$와 핵심 3대 금융 통제 파라미터 집합 $\{\theta_{\text{GARCH}}, \theta_{\text{tail}}, \theta_{\text{regime}}\}$에 대해, 다른 파라미터를 정상 기준점 $\theta^*$로 고정한 상태에서 각 파라미터를 극단 수준으로 스위핑할 때 발생하는 CRPS 증가율 $\Delta \text{CRPS}$와 90% 명목 커버리지 이탈도 $|\text{Cov} - 0.90|$는 **체제전환(Regime Switching, $\theta_{\text{regime}}$) 축에서 최대**이다:
  $$\Delta \text{CRPS}(\theta_{\text{regime}}) > \max(\Delta \text{CRPS}(\theta_{\text{GARCH}}), \Delta \text{CRPS}(\theta_{\text{tail}}))$$
  $$|\text{Cov}(\theta_{\text{regime}}) - 0.90| > \max(|\text{Cov}(\theta_{\text{GARCH}}) - 0.90|, |\text{Cov}(\theta_{\text{tail}}) - 0.90|)$$
* **고등학생을 위한 쉬운 해설**:
  - *비유*: 시험 볼 때 문제가 좀 까다롭거나(변동성), 가끔 엄청 어려운 킬러 문항이 나오는 것(두꺼운 꼬리)은 우등생 AI가 어느 정도 점수를 방어합니다.
  - 하지만 **갑자기 중간에 "지금부터 수학 시험 대신 프랑스어 시험으로 바뀐다"며 시험 규칙 자체가 뒤바뀌는 것(체제전환)**은 AI가 완전히 멘붕에 빠져 찍는 것보다 못하게 됩니다.
  - 즉, TSFM의 신뢰도를 파괴하는 진범은 단순한 '변동성'이 아니라 **'국면(체제)의 급변'**이라는 가설입니다.

---

### 가설 2 (H2. 문헌 모순 해소 및 실측 매핑 가설 — 미국 5종목 중심)
* **수리적 정의**:
  선행연구 2606.27100(10개 중 8개 승리 주장)에서 무작위 보행을 통계적으로 이긴 유일한 2건(AMZN, GOOG, $p=0.0421$)과 기각 실패한 8건(AAPL, JPM, META 등, $p=0.595\sim 0.9999$)의 승패 차이는, 대상 자산 $i$의 통계적 특성 벡터 $\mathbf{s}_i = [\alpha_i+\beta_i, \nu_i, \lambda_i^{\text{regime}}]^\top$가 모델 $\mathcal{M}$의 가상 붕괴 임계 영역 $\Omega_{\text{fail}}$ 내부에 속하는지 여부와 일치한다:
  $$p_{\text{DM}}(\text{AMZN}, \text{GOOG}) < 0.05 \iff \mathbf{s}_{\text{tech}} \notin \Omega_{\text{fail}}$$
  $$p_{\text{DM}}(\text{Others}) \ge 0.05 \iff \mathbf{s}_{\text{others}} \in \Omega_{\text{fail}}$$
* **고등학생을 위한 쉬운 해설**:
  - *비유*: 어떤 연구자는 "자동차가 잘 달린다"고 하고, 어떤 연구자는 "차가 퍼졌다"고 싸우는데, 그 이유는 차를 몰았던 '도로의 비포장 정도'가 달랐기 때문입니다.
  - 우리는 가상 실험실에서 찾은 **"이 차는 자갈 크기가 몇 cm 이상이면 퍼진다"는 파괴 임계선**을 가지고, 실제 주식들의 자갈 크기(통계량)를 재서 승패의 원인을 과학적으로 판정합니다.

---

### 가설 3 (H3. 무재학습 적응형 사후 보정 유효성 가설)
* **수리적 정의**:
  동결된(Frozen) TSFM의 예측 분위수 $\hat{q}_\alpha(x)$에 대해, 국소적 오차 정보를 반영한 적응형 콘포멀 사후 보정 $\mathcal{C}_t$를 적용한 보정 분위수 $\tilde{q}_\alpha(x) = \hat{q}_\alpha(x) + \mathcal{C}_t$는, 파인튜닝 없이도 붕괴된 가상/실측 금융 시나리오에서 90% 명목 커버리지를 오차 범위 $\pm 2\%$ 이내로 복원한다:
  $$|\mathbb{P}(y_{t+h} \in [\tilde{q}_{0.05}, \tilde{q}_{0.95}]) - 0.90| \le 0.02$$
* **고등학생을 위한 쉬운 해설**:
  - AI를 다시 훈련시키는 데 돈(GPU)과 시간을 쓰지 않고, 뒤에서 똑똑한 **'수학적 교정 안경(사후 보정)'**만 씌워줘도 AI가 약속했던 90% 신뢰도를 완벽하게 회복할 수 있다는 가설입니다.

## 3. 핵심 3대 통제 메커니즘 수식 명세 (FinStressTS 축소안 기반)

본실험에서는 6축 중 금융의 가장 본질적인 3축에 집중합니다. (15개 시나리오 = 3축 × 5레벨)

```
[핵심 3대 통제 메커니즘 수학 공식]

 1. 변동성 군집:  sigma_t^2 = omega + alpha * eps_{t-1}^2 + beta * sigma_{t-1}^2
 2. 두꺼운 꼬리:   eps_t ~ Student-t(nu),   nu in [2.5, 30.0]
 3. 체제전환:     y_t = mu_{S_t} + sigma_{S_t} * eps_t,   P = [[p11, p12], [p21, p22]]
```

1. **축 1: GARCH(1,1) 변동성 군집 (Volatility Clustering)**:
   $$\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$$
   - *5단계 통제 레벨*: 지속성 $\alpha + \beta \in \{0.30, 0.60, 0.85, 0.95, 0.98\}$.
   - 레벨이 올라갈수록 충격의 여진이 오래 지속됩니다.
2. **축 2: Student-t 두꺼운 꼬리 (Fat Tails)**:
   $$\epsilon_t \sim t_\nu, \quad \nu \in \{30.0, 10.0, 5.0, 3.5, 2.5\}$$
   - 자유도 $\nu$가 $30$(정규분포에 근접)에서 $2.5$(극단적 블랙스완 빈발)로 떨어지며 극단적 폭락 위험을 조절합니다.
3. **축 3: 마르코프 체제전환 (Markov Regime Switching)**:
   $$r_t = \mu_{S_t} + \sigma_{S_t} \epsilon_t, \quad S_t \in \{1, 2\}$$
   - *5단계 통제 레벨*: 전이확률 $p_{12}, p_{21} \in \{0.02, 0.05, 0.10, 0.20, 0.35\}$.
   - 레벨이 올라갈수록 상승장과 폭락장이 정신없이 뒤바뀝니다.

*(참고: HAR 다중스케일, 호크스 점프, 영과잉 3축은 본실험 완료 후 시간 여력이 있을 때 부록 확장 실험으로 수행)*

## 4. 3층 신뢰도 평가 공식

### 4.1 불편 추정 CRPS 공식
예측 샘플 $\{X^{(1)}, \dots, X^{(S)}\}$와 실제 관측값 $y$에 대해, 샘플 수 편향을 제거한 불편 추정량을 사용합니다:
$$\widehat{\text{CRPS}}(F, y) = \frac{1}{S}\sum_{i=1}^S |X^{(i)} - y| - \frac{1}{2S(S-1)}\sum_{i=1}^S \sum_{j=1}^S |X^{(i)} - X^{(j)}|$$

### 4.2 일측 Diebold-Mariano (DM) 통계 검정
$$d_t = L(\text{TSFM}_t) - L(\text{RW}_t), \quad \text{DM} = \frac{\bar{d}}{\sqrt{\widehat{\text{LRV}}(\bar{d})/T}} \times \text{HLN 보정}$$
- $p < 0.05$일 때만 "동전 던지기를 유의미하게 이겼다"고 엄밀히 판정합니다.
