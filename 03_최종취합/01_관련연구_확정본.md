## 1. 선행연구 지형의 총괄 요약 — 무엇이 이미 있고 무엇이 비었는가?

학술 연구에서 가장 위험한 착각은 "아무도 안 한 완전히 새로운 빈자리"라고 섣부르게 단정하는 것입니다. 정밀한 문헌 조사를 거친 우리의 1차 판정은 **"부분 선점(Partially Preempted)"**이었습니다.

* **이미 존재하는 것들**:
  1. **FinStressTS (arXiv 2606.03184, KDD 2026)**: 금융 시계열의 6대 통계적 성질(변동성 군집, 다중 스케일, 두꺼운 꼬리, 체제전환, 점프, 영과잉)을 컴퓨터로 통제하여 생성하는 합성 벤치마크를 이미 발표했습니다. 문제의식이 우리와 매우 유사합니다.
  2. **단일 축 통제 실험들**: Frequency Matters(2511.05619, 주파수 불일치), Noisy Periodic(2501.00889, 노이즈 강도), Trend strength(2607.19383, 트렌드 강도) 등 합성 데이터로 TSFM의 한계를 시험한 연구들도 여럿 존재합니다.
* **그러나 결정적으로 비어 있는 것들 (The Unfilled Gaps)**:
  1. **사전학습 TSFM의 완벽한 부재**: FinStressTS 논문은 밑바닥부터 새로 학습시키는 전통 딥러닝 모델 15개만 썼을 뿐, **Chronos, Moirai, TimesFM 같은 사전학습 파운데이션 모델은 단 한 줄도 테스트하지 않았습니다**. ⚠️ **[2026-09-23 27차 정정] "저자들이 사전학습 모델 시험을 미래 과제로 명시했다"는 서술은 사실이 아님** — 원문 §6 Limitations(공식 PDF p.12) 전수 재확인 결과 해당 문장은 존재하지 않으며, 실제 한계점은 (1)limit order book 미모사, (2)6개 메커니즘의 대안적 DGP 미탐색, (3)fixed-horizon만 다루고 multi-step/online adaptation/decision-aware 평가 미포함, (4)15개 모델 평가의 지속적 갱신 필요성뿐임. 이 오류는 진행상황.md "❌ 사용 금지 근거" 목록에 이미 2026-08-24(13차)에 거짓으로 판명·등재되어 있었음에도 이번 확정본 작성 과정에서 다시 삽입된 것으로, **재발 방지를 위해 반드시 진행상황.md의 사용 금지 근거 목록을 매 작성 시 대조할 것.**
  2. **도메인과 축의 한계**: Frequency Matters 등은 금융이 아닌 '모바일 게임'이나 일반 기상 데이터를 다뤘고, 오직 1개의 축(주파수)만 테스트했습니다. 금융의 복합적인 6대 파도를 다루지 못했습니다.
  3. **실측 시장과의 연결 부재**: 가상 데이터에서 얻은 실패 지점과 실제 미국/한국 주식 시장의 통계량을 1:1로 맞비교(Mapping)한 연구는 지구상에 단 1편도 없었습니다.
  4. **확률적 불확실성 평가의 부재**: 대다수 금융 벤치마킹 연구는 내일 주가가 맞았냐 틀렸냐(MAE, MSE)만 보았을 뿐, "AI가 자기 확신을 얼마나 과장하고 있는가(캘리브레이션 붕괴)"를 다루지 않았습니다.

따라서 본 연구가 깃발을 꽂는 자리는 **[사전학습 TSFM] × [금융 6대 메커니즘 다축 합성 통제] × [불편추정 CRPS 및 캘리브레이션 3층 평가]**라는 세 원의 교집합이며, 이 자리는 완벽하게 비어 있습니다.

## 2. 시계열 파운데이션 모델(TSFM)의 구조와 확률적 출력 방식

### 2.1 TSFM이란 무엇이며 어떻게 미래를 예측하는가?
전통적인 AI는 특정 회사의 주가 데이터(예: 삼성전자)만 가져다가 그 데이터로만 공부하고 예측했습니다(Local/Task-specific 모델). 반면 **시계열 파운데이션 모델(TSFM)**은 세상에 존재하는 온갖 시계열 데이터를 미리 거대하게 사전학습(Pre-training)한 뒤, 처음 보는 데이터가 주어져도 추가 학습 없이 즉시 미래를 맞추는 **제로샷(Zero-shot)** 능력을 지향합니다.

우리가 조사한 주요 TSFM들은 미래의 불확실성을 표현하기 위해 서로 다른 3가지 방식으로 확률을 출력합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   [TSFM의 3가지 확률적 출력 메커니즘]                  │
├────────────────────────────────────────────────────────────────────────┤
│ (1) 이산 토큰 양자화형 (Chronos):                                      │
│     실수 숫자를 4096개 바구니(Bin)로 쪼개 언어 토큰처럼 단어화.         │
│     ChatGPT처럼 다음 단어(바구니 번호)를 확률적으로 샘플링.            │
├────────────────────────────────────────────────────────────────────────┤
│ (2) 혼합 모수 분포형 (Moirai 1.0, Toto, Lag-Llama):                   │
│     수학 공식(Student-t, 로그정규 등)의 모수(평균, 분산, 자유도)를 출력. │
│     두꺼운 꼬리를 수학적으로 직접 표현 가능.                           │
├────────────────────────────────────────────────────────────────────────┤
│ (3) 분위수 직접 최적화형 (Chronos-Bolt, Chronos-2, Moirai 2.0):        │
│     10%, 50%, 90% 같은 분위수(Quantile) 자체를 핀볼 손실함수로 학습.   │
│     CRPS 평가 지표와 수학적으로 1:1 완벽 정합.                         │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.2 [공식 팩트체크 종결] Moirai의 사전학습 코퍼스 (LOTSA Table 2)
과거 요약본에서 원문 확인 실패로 "확인 불가" 처리되었던 Moirai의 학습 데이터 구성은, 세일즈포스 공식 원본 PDF(ICML 2024, 25쪽) **p.5 Table 2**와 **p.15 Table 14**를 전수 대조하여 완벽하게 팩트가 확정되었습니다.

* **공식 실측치**: LOTSA 코퍼스 전체 관측치는 **27,646,462,733개 (약 276억 개)**입니다.
* **경제/금융(Econ/Fin) 도메인의 실체**:
  - 데이터셋 구성: 총 19종(세부 빈도 포함 23개 서브셋: M1~M4 경진대회 금융 서브셋, CIF 2016, Exchange Rate, FRED 거시지표, Bitcoin 18개 시계열 등)
  - 관측치 수: **24,919,596개 (약 2,490만 개)**
  - 전체 대비 비중: **정확히 0.10%** (1,000개 중 1개 꼴)
* **내용물의 실체**: LOTSA 부록 Table 14를 전수 대조한 결과, M1~M4 금융 서브셋, CIF 2016, 환율(Exchange Rate), 연준 거시지표(FRED), 비트코인(18개 시계열) 등 거시·경진대회 시계열로만 구성되어 있으며, **개별 상장 기업의 일별 주식 수익률 시계열은 단 1건도 포함되지 않았음(0%)**이 확인되었습니다.
* **고등학생 비유**: 276쪽짜리 거대한 백과사전에서 경제·금융 관련 내용은 겨우 0.2쪽 수준이며, 그마저도 거시지표와 환율 위주라 개별 기업 주가 동학은 학습되지 않았습니다.

### 2.3 [공식 팩트체크 종결] Chronos의 사전학습 코퍼스 (Appendix B.2)
아마존이 발표한 Chronos 공식 출판본 PDF(TMLR 10/2024, 43쪽)의 **부록 B.2(p.30~33)**와 **표 3(p.31)**을 1:1로 전수 대조하였습니다.
* **결과**: Chronos 학습에 사용된 55개 데이터셋 중 금융 도메인은 CIF 2016(은행 시뮬레이션), Exchange Rate(국가 간 환율), FRED-MD(월별 거시지표), NN5(ATM 현금 출금)뿐이며, **개별 상장 기업의 주식 시계열은 단 1건도 없음(None)**이 공식 확인되었습니다.

## 3. 확률 예측의 평가 이론: AI의 거짓말을 밝혀내는 수학적 도구

### 3.1 점 예측(Point Forecast)의 한계: 왜 평균값만 보면 망하는가?
내일 삼성전자 주가가 70,000원이라고 딱 하나의 숫자로 찍어 맞추는 것을 '점 예측'이라고 합니다. 하지만 주식 시장에서 점 예측은 거의 쓸모가 없습니다. 내일 70,000원이 될 확률이 99%인 것과, 50,000원부터 90,000원 사이에서 미친 듯이 널뛸 확률이 반반인 것은 투자 전략과 리스크 관리가 완전히 다르기 때문입니다. 따라서 현대 금융 AI는 반드시 **"어떤 범위 안에 들어올 확률이 몇 %인가"를 나타내는 확률 분포**를 내놓아야 합니다.

### 3.2 불편 추정 CRPS (Continuous Ranked Probability Score)
* **쉬운 설명**: CRPS는 날씨 예보에서 내일 강수 확률 분포를 발표했을 때, 그 예보가 실제 날씨와 얼마나 잘 맞았는지를 채점하는 종합 성적표입니다. 점수가 0에 가까울수록 완벽합니다.
* **수학적 엄밀성과 함정 (FinStressTS의 오류 교정)**:
  - 모델에서 몬테카를로 샘플 경로 $S$개를 뽑아 CRPS를 계산할 때, 표준 통계학 공식(Gneiting & Raftery, 2007)은 샘플 간 차이의 계수로 불편 추정량인 **$\frac{1}{S(S-1)}$**을 사용하도록 규정합니다.
  - 그러나 선행 벤치마크인 FinStressTS는 공식 구현 코드에서 편향 추정량인 **$\frac{1}{2S^2}$**을 잘못 사용했습니다. 샘플 수 $S$가 작을수록 오차가 인위적으로 왜곡되는 버그입니다.
  - 본 연구는 공식 원본 대조를 통해 이를 규명하였으며, **모든 TSFM 평가에서 통계학적으로 엄밀한 불편 추정량(Unbiased Estimator)을 채택**합니다.

### 3.3 캘리브레이션 3층 구조 (PIT와 커버리지)
AI가 내놓은 확률이 진짜 신뢰할 수 있는지를 우리는 3단계 피라미드로 철저하게 해부합니다.
1. **1층: 불편 추정 CRPS** — 전체적인 확률 오차 점수 (단일 숫자 채점).
2. **2층: PIT (Probability Integral Transform) 히스토그램** — AI의 심리 진단:
   - 예측 분포에 실제 정답을 대입했을 때의 누적 확률값을 모아 히스토그램을 그립니다.
   - 이상적인 AI는 모든 구간이 평평한 **직사각형(균등분포)**이 나옵니다.
   - 만약 양쪽 끝이 솟아오른 **U자 모양**이 나온다면: AI가 미래를 너무 좁게 확신하고 큰소리치다가 정답이 맨날 양극단으로 빗나간 **'근거 없는 과신(Overconfidence)'** 상태임을 뜻합니다.
3. **3층: 명목 커버리지와 구간 점수(Interval Score)**:
   - "90% 확률 구간"을 제시했을 때 실제 주가가 90% 들어오는지($\text{Coverage} \approx 0.90$) 확인하고, 무작정 구간을 태평양처럼 넓혀서 맞추는 꼼수를 막기 위해 구간의 너비(폭)에 엄격한 벌점을 매깁니다.

## 4. 금융 시계열 합성 벤치마크: 컴퓨터 안의 가상 주식 실험실

### 4.1 왜 실제 주식 데이터만으로는 원인을 못 밝히는가?
실제 주식 시장 데이터(삼성전자, 애플 등)는 모든 요인이 한꺼번에 뒤섞여 있습니다. 오늘 주가가 떨어진 게 금리 때문인지, 전쟁 때문인지, 작전 세력의 장난인지, 회사의 실적 때문인지 칼로 자르듯 분리해낼 수 없습니다. 그래서 수많은 선행연구들이 "TSFM을 주식에 써보니 안 되더라"라는 하소연만 하고 끝났던 것입니다.

### 4.2 FinStressTS의 6대 금융 메커니즘
FinStressTS(KDD 2026)는 금융계량경제학의 6가지 대표적인 현상(Stylized Facts)을 수학 공식으로 만들어서, **다른 모든 조건은 얼려두고 오직 하나의 성질만 레버를 돌려가며 AI의 반응을 볼 수 있는 완벽한 가상 실험실**을 구축했습니다.

```
[가상 실험실의 6대 조절 레버]

 [레버 1: GARCH]      지진의 여진처럼 변동성이 몰려다니는 강도를 조절 (0.1 ~ 0.99)
 [레버 2: HAR]        단타, 중기, 장기 투자자의 기억 지속성을 조절
 [레버 3: Fat-tails]  정규분포에서 블랙스완 극단 폭락이 터지는 빈도를 조절 (자유도 30 -> 2.5)
 [레버 4: Regime]     상승장과 하락장이 하룻밤 사이에 뒤바뀌는 빈도를 조절
 [레버 5: Hawkes]     악재가 터졌을 때 도미노처럼 연쇄 폭락하는 전염성을 조절
 [레버 6: ZIP]        거래가 뚝 끊기는 정체 비율을 조절
```

* **Pretrained TSFM의 선방 보고 (arXiv 2606.27100, 37p PDF)**:
  - 애플, 아마존 등 미국 5개 대형주에서 TSFM이 10개 과제 중 8개를 이겼다고 주장했습니다.
* **통계적 진실 규명 (Table 7 전수 대조)**:
  - 우리가 원본 PDF **p.29 Table 7**[2026-09-23 27차 정정: p.10은 오기]의 일측 Diebold-Mariano(DM) 검정 $p$-value를 전수 확인한 결과, 통계적으로 유의미하게($p < 0.05$) 무작위 보행(랜덤워크)을 이긴 것은 **AMZN(Chronos, $p=0.0421$)과 GOOG(Moirai-2.0, $p=0.0421$) 단 2건뿐**이었습니다.
  - 나머지 8개 과제는 $p$-value가 $0.59 \sim 0.99$로 나와서, 단일 종목 단기 표본에서는 무작위 보행 대비 통계적 유의성이 일관되게 입증되지 않았음이 확인되었습니다.

## 7. 실험 설계에 반영할 핵심 방법론 원칙

1. **CRPS 계산 시 불편 추정량 고수**: $\frac{1}{S(S-1)}$을 엄격히 적용하여 샘플 수 차이에 따른 오염을 차단합니다.
2. **사전학습 코퍼스 누출 통제**: Chronos(주식 0건)와 Moirai(금융 0.10%)의 코퍼스 팩트를 명시하고, 순수한 제로샷(Zero-shot) 평가임을 보장합니다.
3. **캘리브레이션 3층 평가 체계**: CRPS 단독 점수에 의존하지 않고, PIT 히스토그램과 구간 점수를 함께 평가하여 AI의 '과신'을 과학적으로 입증합니다.
