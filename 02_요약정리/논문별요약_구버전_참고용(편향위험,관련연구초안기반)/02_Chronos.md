- **근거 문서**: `03_최종취합/관련연구_초안.md` §2.1, `02_요약정리/하위갈래A`

## 한 줄 요약
시계열 값을 스케일링·양자화해 언어모델 토큰처럼 다루고, T5류 인코더-디코더를 범주형
분포 위에서 자기회귀 학습시켜 시계열 예측을 "언어모델링 문제"로 취급하는 TSFM.

## 방법 / 확률적 출력
scale → quantize(양자화) → tokenize → cross-entropy로 다음 토큰 분포 학습 → 추론 시
자기회귀적으로 토큰을 샘플링해 다중 궤적(sample paths) 생성. 하위갈래A 분류상
**"이산 토큰 샘플 경로형"**(유형 iii) — 경험적(empirical) CRPS 계산이 필요하다.
샘플 수는 원문 기준 20개(Toto의 100~200개보다 적음, 몬테카를로 분산에 영향).

## 사전학습 코퍼스와 금융 노출 — 누출 통제 1순위
사전학습 코퍼스 도메인 나열에 "finance"가 명시적으로 포함되어 있음(비중은 미기재).
→ look-ahead 누출(사전학습 때 이미 금융 패턴을 봤을 가능성) 통제 대상 1순위.

## 후속 모델 계열
- **Chronos-Bolt**: 직접 다단계 quantile 예측(자기회귀 없이 한 번에 여러 시점의
  분위수 출력). 별도 1차 arXiv 논문 없음 — GitHub/HF 문서로만 확인, 인용 시 주의.
- **Chronos-2**(arXiv 2510.15821): 명시적 Quantile Head, 학습목적함수 자체가
  quantile regression objective.
