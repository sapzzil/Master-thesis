# 석사학위논문: 사전학습 시계열 모델의 금융 수익률 예측구간

한양대학교 인공지능융합대학원 석사학위논문 작업 저장소입니다.

- 제목(안): 사전학습 시계열 모델의 금융 수익률 예측구간: 오차의 출처와 재학습 없는 사후보정
- 부제: 실측 기반 합성 데이터 통제 실험과 미국·한국 대형주 실증

## 연구 요약

사전학습 시계열 모델(TSFM) 4종(Chronos-T5, Chronos-2, TimesFM-2.5, Moirai-2.0)이 내는 주가 수익률 80% 예측구간이 실제로 80% 맞는지(커버리지)를 평가했습니다.

- RQ1 진단: 구간이 틀어지는 원인이 금융 데이터의 특성(변동성 군집, 두꺼운 꼬리, 국면 전환)인지, 모델과 입력 설정인지
- RQ2 실증: 실제 미국·한국 대형주 10종목(2017~2026)에서 가장 단순한 기준(RW)보다 나은지
- RQ3 처방: 재학습 없는 사후보정(ACI-CQR)으로 커버리지를 80%로 되돌릴 수 있는지

결론: 오차는 금융 특성보다 모델과 입력 설정에서 오고(특성 없는 데이터에서도 75~88%), 사후보정으로 모든 경우 평균 커버리지가 80%로 복원됩니다. 분포 정확도는 RW 수준입니다.

## 현재 상태

초고 완성, 지도교수 검토 대기. 단계별 진행은 [`00_메타/진행상황.md`](00_메타/진행상황.md)에 요약하고, 모든 결정의 경위는 [`00_메타/결정로그.md`](00_메타/결정로그.md)에 기록합니다.

## 원고 빌드

```
python 05_논문작성/gen/build.py
```

`05_논문작성/원고/`의 md를 이어 붙여 통합본 md와 docx 두 개(본문, 요약본)를 만듭니다. 학교 양식(A4, 바탕·굴림)은 Word 기준이므로 쪽 나눔은 Word에서 확인합니다. Word에서 docx를 직접 고쳤다면 `원고/`의 md에도 같은 수정을 반영해야 다음 빌드에서 사라지지 않습니다.

## 실험 재현

실행 환경과 패키지 버전, 모델별 추론 설정, 실험 절차와 조치 기록은 논문 부록 A에 있습니다(Python 3.11, PyTorch 2.5.1, chronos-forecasting 2.3.2, timesfm 3.0.2, uni2ts 2.0.0, arch 8.0.0, RTX 3080 10GB). 대용량 예측 파일(`scored_v4.parquet`, `real_all.parquet` 등)은 git에 포함하지 않으며, `src_v4`·`src_v4_econ` 코드로 다시 만들 수 있습니다.
