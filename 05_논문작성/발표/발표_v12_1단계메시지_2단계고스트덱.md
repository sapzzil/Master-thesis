# 발표 자료 새로 짜기 (주장 중심): 1단계 메시지, 2단계 고스트 덱 (2026-11-26, 3판)

3판 원칙(사용자 지적 반영)
- "어긋난다" 같은 모호한 말을 쓰지 않는다. 무엇이 무엇과 얼마나 다른지 쓴다(예: 커버리지가 80%와 다르다, 적정 범위 78~82%를 벗어난다).
- 문장마다 주어·목적어·서술어를 분명히 쓴다. 뼈대만 읽어도, 논문을 처음 보는 사람도 이해할 수 있어야 한다.
- 용어는 처음 나올 때 뜻을 함께 쓴다.
- 제목은 짧은 주제, 결론은 제목 아래 한 줄 메시지로.

근거: 원고 v3 국문요지, 1장, 3.1절, 4~7장, 표 7-1. 새 숫자 없음.

## 0. 용어 (처음 보는 사람 기준)
| 용어 | 뜻 |
|---|---|
| TSFM (사전학습 시계열 모델) | 많은 시계열로 미리 학습해 두어, 새 데이터에 추가 학습 없이 바로 예측을 내는 모델. 본 연구는 Chronos-T5, Chronos-2, TimesFM-2.5, Moirai-2.0 |
| 분위수 예측 | 다음 날 수익률이 "이 값보다 작을 확률이 10%, 20%, …, 90%"인 값 9개를 내는 것 |
| 80% 예측구간 | 10% 분위수와 90% 분위수 사이 범위. "다음 날 수익률이 80% 확률로 이 안에 든다"는 뜻 |
| 커버리지 | 실제 수익률이 예측구간 안에 든 날의 비율. 80% 구간의 목표는 80% |
| 커버리지 오차 | 커버리지와 목표 80%의 차이 |
| VaR 10% | 하루 손실이 이 값을 넘는 날이 10%뿐이라는 손실 한도. 80% 구간의 아래 끝과 같다 |
| 금융 특성 | 변동성 군집(큰 변동이 며칠씩 이어짐), 두꺼운 꼬리(아주 큰 수익률이 정규분포보다 자주 나옴), 국면 전환(평온기와 격변기가 번갈아 옴) |
| L1 | 금융 특성을 하나도 넣지 않은 합성 데이터(정규분포) |
| RW | 과거 수익률의 평균과 표준편차로 만든 정규분포 구간. 가장 단순한 기준 모형 |
| ACI-CQR | 모델을 다시 학습시키지 않고, 실제값이 구간을 벗어났는지에 따라 매일 구간 양 끝을 조정하는 사후보정 방법 |

참고: TSFM이 직접 내는 것은 다음 날 로그수익률의 분위수 9개다(가격을 입력한 조건은 모델이 낸 가격 분위수를 수익률로 바꾼다). 80% 예측구간은 그중 10%·90% 분위수로 만든다(3.1절).

## 1단계. 핵심 메시지

### 이야기 틀
- 상황: TSFM은 추가 학습 없이 다음 날 주가 수익률의 분위수를 예측한다. 이 분위수로 80% 예측구간을 만들면, 구간의 아래 끝을 하루 손실 한도(VaR 10%)로 쓸 수 있다.
- 문제: 80% 예측구간이라면 실제 수익률이 그 안에 드는 날이 80%여야 한다. 그러나 TSFM이 금융 수익률에서 이 비율(커버리지)을 지키는지는 검증되지 않았다. 또 커버리지가 80%와 다를 때, 기존 연구는 그 원인을 금융 데이터의 특성에서 찾았다.
- 질문:
  - RQ1: 커버리지 오차는 금융 특성 때문에 생기는가, 모델과 입력 설정 때문에 생기는가?
  - RQ2: 실제 주가에서 TSFM의 커버리지와 분포 정확도는 단순 기준 모형과 비교해 어떠한가?
  - RQ3: 모델을 다시 학습시키지 않는 사후보정으로 커버리지를 80%로 되돌릴 수 있는가?
- 답:
  - RQ1: 본 실험 범위에서 TSFM의 커버리지는 금융 특성보다 모델과 입력 설정에 따라 더 크게 달라졌다.
  - RQ2: 실제 주가의 커버리지는 특성 없는 합성 데이터의 커버리지와 비슷했다. 그러나 TSFM의 분포 정확도는 단순 기준 모형(RW)보다 높지 않았다.
  - RQ3: 사후보정(ACI-CQR)은 모든 모델·조건에서 평균 커버리지를 80%로 되돌렸다. 그 대가로 구간 폭이 넓어졌다.

### 한 문장 요약
TSFM이 낸 금융 수익률 예측구간의 커버리지는 금융 데이터의 특성보다 모델과 입력 설정에 따라 더 크게 달라졌고, 이 커버리지 오차는 실제 적용 전에 합성 데이터로 점검하고 모델을 다시 학습시키지 않는 사후보정으로 평균 80%까지 되돌릴 수 있다.

### 세 주장과 단서
| | 주장 | 근거 숫자 | 연구 질문 |
|---|---|---|---|
| 주장 1 | TSFM의 커버리지 오차는 금융 특성보다 모델과 입력 설정에서 더 크게 생긴다 | L1에서도 커버리지 75~88%, 16개 중 8개가 78~82% 밖 / 기본 설정 하나로 14% / 특성을 실측 최대로 넣어도 대부분 3%p 이내, 차이의 90%는 모델·조건, 7%는 특성 / 두꺼운 꼬리는 80% 구간 커버리지를 높이고 98~99% 구간은 낮춤 | RQ1 |
| 주장 2 | 실제 주가의 커버리지도 합성 데이터와 비슷하므로, 실제 적용 전에 합성 데이터로 설정을 점검할 수 있다 | 실제와 L1의 차이 평균 1.1%p / 크게 벗어나는 두 설정(87.7%, 17%)이 합성 데이터에서 먼저 드러남 / 2%p 이내의 작은 차이는 합성 데이터로 맞히지 못함(p = 0.07) | RQ2 |
| 주장 3 | 사후보정은 모델을 다시 학습시키지 않고 평균 커버리지를 80%로 되돌리며, 그 대가로 구간 폭이 넓어진다 | 합성 323개·실제 19개 모두 77~83% / 폭은 이상적인 구간보다 5~48% 넓음 / VaR 검정 통과 8 → 14개 / 변동이 큰 시기에는 76~79%로 낮게 남음 | RQ3 |
| 단서 | TSFM의 분포 정확도는 단순 기준 모형보다 높지 않다 | 16개 중 12개가 RW보다 낮음, 1년 조건 모두 GARCH-t보다 낮음 / 중앙값으로 사고파는 규칙은 계속 보유보다 수익이 낮음 | RQ2 |

### 기여와 주장의 연결
| 기여 | 내용 | 뒷받침 |
|---|---|---|
| C1 방법론 | 실측 강도로 만든 합성 데이터(특성 없는 L1 포함)로 실제 적용 전에 모델과 설정을 점검하는 절차를 제시했다 | 주장 2 |
| C2 평가 관점 | 두꺼운 꼬리가 80% 구간과 98~99% 구간의 커버리지를 반대 방향으로 바꾼다는 이론 계산을 TSFM 예측구간에서 확인했다 | 주장 1 |
| C3 실증 | 최신 TSFM 4종을 미국·한국 대형주, 약 10년, 입력 4조건에서 실험 전에 정한 기준으로 평가하고 모든 조건을 보고했다 | 전체 |
| C4 실무 | 설정 점검, 사후보정, 용도 제한으로 이어지는 도입 절차를 제시했다 | 주장 3, 단서 |

### 심사위원이 기억할 세 가지
1. 같은 데이터에서도 TSFM의 커버리지는 모델과 설정에 따라 75~88%로 달랐고, 설정 하나로 14%까지 떨어졌다.
2. 합성 데이터로 실제 적용 전에 설정을 점검할 수 있고, 사후보정으로 평균 커버리지를 80%로 되돌릴 수 있다.
3. 그래도 TSFM의 분포 정확도는 단순 기준 모형보다 높지 않으므로, 방향 예측에는 쓰지 않는다.
