# 발표 자료 새로 짜기: 1단계 메시지, 2단계 고스트 덱 (2026-11-26, 5판)

## 작성 원칙 (사용자 지적 모음)
1. 사실을 정확하게: TSFM이 직접 내는 것은 다음 날 로그수익률의 분위수 9개이고, 80% 예측구간은 그중 10%·90% 분위수로 만든다. 숫자는 논문에 있는 값만 쓰고, 예시 숫자는 계산 근거를 함께 적는다.
2. 문장은 주어·목적어·서술어를 분명히 쓴다. "어긋난다"처럼 무엇이 얼마나 다른지 모르는 말을 쓰지 않는다. 조어·번역투·"A가 아니라 B" 대구를 피한다.
3. 처음 보는 사람도 이해할 수 있게 쓰되, 심사위원이 아는 기초(정규분포, 손실 쪽·이익 쪽 등)를 길게 풀지 않는다. 용어는 처음 나올 때 한 번 정의한다.
4. 제목은 짧은 주제로 쓴다. 결론(요약 문장)은 제목 아래 한 줄 메시지로 따로 둔다.
5. 한 장에는 메시지 하나와 근거(그림·표) 하나를 둔다. 제목과 내용이 맞아야 한다.
6. 구성은 논문과 같다. 결과는 연구 질문 그대로 묶는다(RQ1 합성 데이터로 금융 특성의 영향 진단, RQ2 실제 주가 실증, RQ3 재학습 없는 사후보정).
7. 답을 먼저 보여 준다. 2쪽 요약에서 질문·답·기여를 먼저 보이고, 결론에서 같은 틀로 다시 짚는다.

## 0. 용어
| 용어 | 뜻 |
|---|---|
| TSFM (사전학습 시계열 모델) | 많은 시계열로 미리 학습해 두어 새 데이터에 추가 학습 없이 예측을 내는 모델. 본 연구는 Chronos-T5, Chronos-2, TimesFM-2.5, Moirai-2.0 |
| 분위수 | "다음 날 수익률이 이 값보다 작을 확률이 10%, 20%, …, 90%"인 값 |
| 80% 예측구간 | 10% 분위수와 90% 분위수 사이의 범위 |
| 명목 커버리지 | 구간이 약속한 비율. 80% 구간이면 80% |
| 실현 커버리지(커버리지) | 실제 수익률이 구간 안에 든 날의 비율 |
| VaR 10% | 하루 손실이 이 값을 넘는 날이 10%라는 손실 한도. 80% 구간의 아래 끝과 같다 |
| 금융 특성 | 변동성 군집, 두꺼운 꼬리, 국면 전환(빈도·크기) |
| L1 | 금융 특성을 하나도 넣지 않은 합성 데이터 |
| RW | 과거 수익률의 평균과 표준편차로 만든 정규분포 구간(기준 모형) |
| ACI-CQR | 모델을 다시 학습시키지 않고, 실제값이 구간을 벗어났는지에 따라 매일 구간의 양 끝을 조정하는 사후보정 방법 |

## 1단계. 핵심 메시지

### 연구 배경과 문제
- TSFM은 추가 학습 없이 다음 날 주가 수익률의 분위수를 예측한다.
- 이 분위수로 80% 예측구간을 만들면, 구간의 아래 끝을 하루 손실 한도(VaR 10%)로 쓸 수 있다.
- 이렇게 쓰려면 실제 수익률이 구간 안에 드는 날이 80%여야 한다(실현 커버리지 = 명목 커버리지).
- 그러나 기존 금융 TSFM 연구는 점 예측 정확도만 비교했고, TSFM 예측구간의 실현 커버리지는 평가하지 않았다.
- 기존 진단 연구(FinStressTS)는 "금융 특성이 예측 모델에 불리하다"고 보았다. 이 관점이 TSFM 예측구간에도 맞는지는 확인되지 않았다.

### 연구 질문과 답
| 연구 질문 | 확인 방법 | 답 | 근거 숫자 |
|---|---|---|---|
| RQ1 진단: 금융 특성이 강해질수록 TSFM 80% 예측구간의 커버리지가 낮아지는가, 아니면 모델과 입력 설정에서 이미 커버리지 오차가 생기는가? | 합성 데이터: 실제 10종목에서 잰 강도로 금융 특성을 하나씩 넣은 17개 시나리오 | 본 실험 범위에서 TSFM의 커버리지는 금융 특성보다 모델과 입력 설정에 따라 더 크게 달라졌다. 커버리지를 낮춘 특성은 변동성 군집뿐이었다 | L1에서도 커버리지 75~88%, 16개 모델·조건 중 8개가 78~82% 밖 / 기본 설정 하나로 14% / 특성을 실측 최대로 넣어도 대부분 3%p 이내, 커버리지 차이의 90%는 모델·조건, 7%는 특성 / 두꺼운 꼬리는 80% 구간의 커버리지를 높이고 98~99% 구간의 커버리지를 낮춤 |

### 한 문장 요약
TSFM이 낸 금융 수익률 80% 예측구간의 커버리지는 금융 특성보다 모델과 입력 설정에 따라 더 크게 달라졌으며, 이 커버리지 오차는 실제 적용 전에 합성 데이터로 점검하고 모델을 다시 학습시키지 않는 사후보정으로 평균 80%까지 되돌릴 수 있다.

### 새로운 점과 기여
| 기여 | 내용 | 뒷받침하는 결과 |
|---|---|---|
| C1 방법론 | 실측 강도로 만든 합성 데이터(특성 없는 L1 포함)로 실제 적용 전에 모델과 설정을 점검하는 절차를 제시했다 | RQ1, RQ2(실제와 L1의 차이 평균 1.1%p) |
| C2 평가 관점 | 두꺼운 꼬리가 80% 구간과 98~99% 구간의 커버리지를 반대 방향으로 바꾼다는 이론 계산을 TSFM 예측구간에서 확인했다 | RQ1 |
| C3 실증 | 최신 TSFM 4종을 미국·한국 대형주, 약 10년, 입력 4조건에서 실험 전에 정한 기준으로 평가하고 모든 조건을 보고했다 | RQ1~RQ3 |
| C4 실무 | 설정 점검, 사후보정, 용도 제한으로 이어지는 도입 절차를 제시했다 | RQ2(분포 정확도의 한계), RQ3 |

### 심사위원이 기억할 세 가지
1. 같은 데이터에서도 TSFM의 커버리지는 모델과 설정에 따라 75~88%로 달랐고, 설정 하나로 14%까지 떨어졌다.
2. 합성 데이터로 실제 적용 전에 설정을 점검할 수 있고, 사후보정으로 평균 커버리지를 80%로 되돌릴 수 있다.
3. TSFM의 분포 정확도는 단순 기준 모형보다 높지 않으므로, TSFM 예측구간은 방향 예측에 쓰지 않는다.

### 한 줄 메시지만 이어 읽기 (가로 논리 점검)
TSFM은 다음 날 수익률의 분위수를 내고, 그 80% 구간의 아래 끝이 VaR가 된다. → 실현 커버리지가 80%와 다르면 손실 한도가 틀린다. → 기존 연구는 이 커버리지를 다루지 않았다. → 본 연구는 합성 데이터와 실제 10종목에 같은 절차를 적용했고, → "금융 특성이 커버리지를 낮춘다"는 관점을 가설로 세웠다. → 특성 없는 데이터에서도 커버리지는 75~88%였고, → 설정 하나로 14%까지 떨어졌으며, → 특성을 최대로 넣어도 대부분 3%p 안에서 움직였다. → 꼬리는 80% 구간 커버리지를 오히려 높였다. → 실제 주가도 합성 데이터와 비슷했지만, → 분포 정확도는 RW보다 높지 않았다. → 사후보정은 모델을 다시 학습시키지 않고 → 평균 커버리지를 80%로 되돌렸고 폭은 5~48% 넓어졌다. → 따라서 설정 점검, 사후보정, 용도 제한의 절차로 써야 한다.
