Q08 · 실험 절차

결과를 본 뒤 Chronos-T5 설정을 바꾼 것이 결론에 유리하게 작용하지 않았나?

모델의 예측을 잘라 내는 생성 제약 하나만 풀었고, 바꾸기 전 결과도 함께 실었다. 다른 모델의 판정은 하나도 바뀌지 않았다.

  • 14%라는 비정상 값을 발견 → 점검 실험으로 원인 확인(가격 입력·값의 크기와 무관, 평균 0 근처 입력에서만)
  • 과제·난수 시드·채점·분석 코드는 그대로, 수익률 조건 2개만 다시 예측
  • 바뀐 것은 Chronos-T5가 다른 모델과 같은 방향을 보이게 된 것뿐. 결론은 바꾸기 전 결과로도 같다
  • TimesFM의 출력 방식은 권장 설정이고 꺼도 과대가 일부만 줄어(87→83~84%) 그대로 둠: 기준은 "예측을 잘라 내는 제약인가"

근거: 3.4절, 부록 A.1·A.2·A.3 · 디펜스 D1-1, D1-2

실험 과정에서 Chronos-T5 수익률 구간의 커버리지가 14%로 비정상인 것을 발견했고, 점검 실험으로 원인을 확인했습니다. 라이브러리의 기본 생성 설정이 모델이 낸 분포를 상위 50칸에서 잘라 내고 있었습니다. 모델의 예측을 그대로 평가하려면 풀어야 하는 제약이라 그 하나만 풀었고, 과제와 난수 시드, 채점과 분석 코드는 그대로 두고 수익률 조건 두 개만 다시 예측했습니다. 바꾸기 전 결과도 부록에 함께 실었습니다. 다른 세 모델의 판정은 하나도 바뀌지 않았고, Chronos-T5에서 바뀐 것도 다른 모델과 같은 방향이 드러난 것이라 결론을 유리하게 만든 것이 아닙니다. 결론은 바꾸기 전 결과로도 같습니다. 반면 TimesFM의 분위수 출력 방식은 라이브러리의 권장 방식이고 꺼도 과대가 일부만 줄어 그대로 뒀습니다. 기준은 "모델의 예측을 잘라 내는 제약인가"였습니다.
