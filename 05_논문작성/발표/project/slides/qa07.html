Q07 · 설계의 타당성

합성 데이터가 실제 시장을 대표한다고 볼 수 있나?

세기를 실측으로 정했고, 특성 없는 합성의 커버리지가 실제 주가와 평균 1.1%p 차이였다. 다만 정밀한 예측력까지 주장하지는 않는다.

  • 특성 세기는 임의가 아니라 실제 10종목에서 측정한 값으로 단계를 정함
  • 오라클 모형 79.3~80.2%로 데이터 생성과 채점 절차가 맞음을 확인
  • "모두 80%"로 짐작해도 평균 차이 2.1%p. 합성이 더 가까운 건 19개 중 12개(p = 0.07), 상관 0.90도 한 점을 빼면 0.78
  • 분명한 쓸모: 크게 어긋나는 조합(TimesFM 1년·가격 88%, 기본 설정 Chronos-T5 14%)은 합성에서 이미 드러났다

근거: 3.2절, 4.1절, 5.4절 · 디펜스 C2 · 대표성(C2)과 검출력(Q05)은 다른 질문

합성 데이터의 특성 세기는 임의로 정하지 않고 실제 10종목에서 측정한 값으로 정했습니다. 참 분포를 아는 오라클 모형은 17개 시나리오 모두 79.3에서 80.2%로, 생성과 채점 절차가 맞다는 것도 확인했습니다. 그리고 특성 없는 합성 데이터의 커버리지가 실제 주가와 평균 1.1%p 차이였습니다. 다만 솔직하게 말씀드리면, 모든 조합을 80%로 짐작해도 평균 차이가 2.1%p이고, 합성이 더 가까운 조합은 19개 중 12개라 통계적으로 확실하지는 않습니다. 상관 0.90도 TimesFM 1년·가격 한 점의 영향이 커서 빼면 0.78입니다. 이 점은 본문에 그대로 적었습니다. 합성 점검이 분명히 쓸모 있는 것은 크게 어긋나는 경우로, TimesFM 1년·가격과 기본 설정 Chronos-T5는 합성 데이터에서 이미 그대로 드러났습니다.
