# 심사 발표 스토리보드 v3 (도식·논문 그림 전부 반영안)

작성 2026-11-18. v2(11/4)의 흐름과 novelty·contribution 구성을 그대로 두고 두 가지를 더했다.

1. **논문에 있는 그림 15개와 표 30개를 모두 발표 자료에 넣는다.** 본편에 넣거나, 본편에서 다 못 넣는 것은 "자료 부록"으로 넣는다. 5절이 대조표다.
2. **도식 9개(D1~D9)와 그래프 3개(G1~G3)를 새로 그린다.** 연구 전체 구조, 합성 데이터 생성, 평가 절차, 보정 순환 같은 방법론과 실무 절차를 그림으로 보인다.

사용자가 준 이미지 3장은 **화면 틀(템플릿)**로만 쓴다. 내용과는 관계없다. 숫자는 모두 원고와 v2(113차 대조본)에서 가져왔고, 새로 계산한 숫자는 없다.

## 3. 새로운 점·기여 정의 (v2와 같음)

**새로운 점**
- N1 질문: 금융 TSFM의 예측구간이 맞는지를 원인까지 진단
- N2 방법: 실측 세기와 공통 난수로 특성 하나씩 통제해, 합성 결과를 실제 주가와 직접 연결
- N3 발견: 오차의 출처는 금융 특성이 아니라 모델·설정이고, 꼬리 효과는 구간 수준에 따라 뒤집힘

**기여**
- C1 점검 절차: 합성 점검으로 크게 어긋나는 모델·설정을 실제에 쓰기 전에 가려냄
- C2 처방 검증: 재학습 없는 보정의 효과와 대가를 함께 수치로 보임
- C3 평가 관점: 80% 구간 하나로 꼬리 위험을 판단하면 틀림
- C4 실증·실무: 4종 × 4설정 × 두 시장 약 10년의 결과를 전부 보고하고, 실무 지침 3가지를 냄

말하지 않는 것:
- ACI-CQR은 기존 방법의 결합이며, 새 보정 방법을 제안한 것이 아니다.
- "최초"라는 표현은 쓰지 않는다.

## 4. 장별 구성

각 장은 [시각 요소] 아래 확인 띠, 출처 순서로 적었다. "논문 그림"과 "논문 표"는 원고의 것을 그대로 쓰고, D·G는 새로 그리는 것이다.

### 1. 표지
- 제목, 부제(실측 기반 합성 데이터 통제 실험과 미국·한국 대형주 실증), 김승민, 지도교수 노영균, 한양대학교 인공지능융합대학원.

### 2. 한 장 요약
- 시각: 카드 3개(진단 75~88% / 처방 80% 복원, 폭 5~48% / 쓰임새 RW 수준 → 위험 측정)와, 그 아래 미니 도식으로 D1의 축소판(상자 4개: 측정 → 합성 → 실증 → 보정).
- 맨 아래 띠: 새로운 점(N1·N2) / 기여(C1·C2) 한 줄.
- 확인: 본문 1.4절, 국문요지.

### 3. 1.1 연구 배경 (1/3): TSFM이란
- 시각: **논문 그림 2-2**(TSFM의 두 가지 입력 방식) 크게.
- 블록: 모델 4종 이름과 공개 시기를 띠로(Chronos-T5, Chronos-2, TimesFM-2.5, Moirai-2.0).
- 파란 상자 "흔한 방식과의 차이": 계열마다 모형을 추정하거나 학습하던 방식 → 내려받아 과거 값만 넣으면 됨.
- 확인: 본문 1.1절, 2.2.3절, 그림 2-2.

### 4. 1.1 연구 배경 (2/3): 구간이 왜 중요한가
- 시각: **D3 문제 전파도**와 **논문 그림 2-3**(분위수, 80% 예측구간, VaR 10%의 관계)을 좌우로 놓는다.
- D3 상자 5개(가로)와 빨간 표시:
  - 과거 수익률 → TSFM → 분위수 9개 → 80% 구간(10%·90% 끝) → VaR 한도·투자 비중
  - 마지막 두 상자 아래에 빨간 말풍선: "구간이 좁으면 한도를 넘는 날이 잦아지고, 넓으면 투자를 필요 이상 줄인다"
  - "바젤 사후 점검도 같은 방식" 회색 메모
- 확인: 본문 1.1절, 2.4절, 그림 2-3.

### 5. 1.1 연구 배경 (3/3): 커버리지
- 시각: **논문 그림 2-4**(예측구간과 커버리지의 예, 가상 40일).
- 보조 표(작게): 좋은 구간 80일 / 너무 좁은 구간 52일 / 너무 넓은 구간 98일(100일 중).
- 확인: 목표 80%, 78~82%(±2%p)를 맞는 범위로 봄. 본문 2.3절, 그림 2-4.

### 6. 2.6 관련 연구 [N1·N2]
- 시각: 왼쪽 **논문 표 2-1**(관련 연구 비교, 본 연구 줄 보라), 오른쪽 **D2 선행연구 위치도**.
- D2: 원 3개를 겹친 그림(금융 TSFM 평가 / 합성 데이터 진단 / 콘포멀 사후보정).
  - 각 원 안에 대표 연구를 적는다: Rahimikia 외·Noguer i Alonso 외 / FinStressTS·Wang 외 / Romano 외·Gibbs·Candès.
  - 세 원이 겹친 가운데에 보라색으로 "본 연구".
  - 각 원 옆에 빨간 글씨로 무엇을 안 했는지 적는다: 점 예측만 / 학습형 모델·CRPS만 / 방법론만.
- 파란 상자 "흔한 방식과의 차이"(상자 3개와 화살표):

### 27. 3.5 사후보정 방법 [C2]
- 시각: 왼쪽 **D7 보정 순환도**, 오른쪽 **논문 그림 2-6**(ACI 조정 예).
- D7 순환(주황 화살표):
  1. [TSFM 원래 구간 l, u]
  2. → [이탈 점수 기록 s = 구간 밖 거리 / 폭]
  3. → [k번째 점수 × 폭만큼 넓히거나 좁힘]
  4. → [보정 구간]
  5. → [다음 날 실제값: 밖이면 err = 1, 안이면 0]
  6. → [α 갱신: α + γ(0.2 − err)]
  7. → 다시 3번으로 돌아간다.
  - 바깥에 회색 상자: "모델은 건드리지 않음(재학습 없음)".
  - 준비 20일 = 기록만.
- 파란 상자 "흔한 방식과의 차이": 일괄 확대(배율을 결과를 보고 정함) 대 보정(그때까지의 실제값만 사용).
- 아래 작게: 콘포멀 분위수 회귀(Romano 외 2019) + 적응형 콘포멀 추론(Gibbs·Candès 2021)의 결합. 새 방법 아님. α = 0.20, γ = 0.05 고정.
- 확인: 본문 3.5절, 2.5절, 그림 2-6.

- 주석: GARCH-t 비정상 값 2건 대체는 영향 없음(**논문 표 6-3**, 자료 부록 A5).

### 29. 6.3~6.4 대가 [C2]
- 시각: **G2 폭 비교 막대**. 이상적인 구간 = 1.0 기준선, 보정 구간 범위는 과거 1년 1.05~1.24, 한 달 1.14~1.48. 옆에 대조군(일괄 확대)의 커버리지 81~86%를 점으로.
- 파란 상자: 일괄 확대는 몇 배로 넓힐지 결과를 봐야 앎(0.8~1.3배) ↔ 보정은 모르는 상태에서 80%에 감.
- 확인: 본문 6.3~6.4절.

### 30. 6.6 시기별 차이 [C2]
- 시각: **G3 시기별 막대**(평온한 달 / 변동이 큰 달 × 보정 전 / 후, 조합 묶음 3개). 아래에 **논문 표 6-4** 원표를 작게.
- 강조 숫자: 두 시기의 차이 10.1%p → 2.9%p(보정 전 최대 22.8%p).
- 빨간 주석: "복원"은 평균 기준. 1년 조합은 변동이 큰 달에 76~79%.
- 확인: 본문 6.6절 표 6-4.

### 31. 5.5 활용 [C4]
- 시각: 위 **논문 그림 5-4**(10종목 동일비중 포트폴리오 누적 수익). 아래 카드 3개는 각각 표 하나를 요약한다.

  - 앞 두 카드는 초록 테두리, 세 번째는 회색.
- 주석: 탐색 분석이며 가설 검정과는 별개다. 원표 세 개는 자료 부록 A6에 넣는다.
