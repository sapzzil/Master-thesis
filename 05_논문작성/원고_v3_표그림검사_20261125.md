# 원고 v3 표·그림·기호 검사 (2026-11-25)

대상: `석사학위논문_초고_v3_김승민.docx`의 표 30개, 그림 15개, 수식, 본문 기호.

**검사 방법**
- **표:** Word 파일 안의 열 너비와 글자 크기로 칸마다 줄바꿈 위치를 계산하였다. 이 방법은 사용자가 Word에서 본 표 3-4의 줄바꿈("하루 변동 (17개 / 시나리오)")을 그대로 재현했다. 다만 글꼴 폭을 근사해 계산했으므로 한두 칸은 Word 화면과 다를 수 있다.
- **그림:** 파일 안의 원본 그림을 하나씩 열어 보았다.

---

## 1. 공통 규칙

1. **칸 안 줄바꿈:**
   - 단어나 괄호 중간에서는 꺾지 않는다. 열 너비를 다시 나눠서 해결한다.
   - 머리글이 두 줄이 되는 것은 괜찮다.
   - "한 달"은 띄어쓰기 자리에서 꺾이지 않도록 묶는다(줄바꿈 없는 공백).
2. **유의성 표시:** *(Holm 보정 후 p < 0.05)로 통일한다. 실질 기준(2%p) 이상은 굵은 글씨로 표시한다. 방향은 +/− 부호로 보이므로 따로 표시하지 않는다.
3. **표 2-1의 ○ × △는 유지한다.** 선행연구 비교표에서 흔히 쓰는 표기다.
4. **원문자 ①②③④는 본문·표·그림에서 모두 뺀다.** 나열은 "(1) (2)" 또는 문장으로 쓴다. 표 3-3 머리글과 그림 3-2의 원문자도 함께 뺀다.
5. **화살표(→):** 표 안의 "보정 전 → 후", "(전체 → 공개 후)"는 유지한다. 본문 문장 안의 화살표 11곳은 "A에서 B로"로 푼다.
6. **그림 축 이름:** "A = B" 꼴의 범례 설명을 축 이름에 넣지 않는다. 그런 설명은 그림 제목 아래 설명으로 옮긴다.

## 4. 수식 문자

| 위치 | 문제 | 수정 |
|---|---|---|
| 2.3.1 "τ 분위수 q_τ는 … P(Y ≤ q_τ) = τ" | 밑줄이 그대로 보임("q_τ") | τ를 아래첨자로 |
| 식 (2.6) "ρ_τ(y, q)" | 같음 | 같음 |
| 식 (2.7) "… ρ_τ(y, F−1(τ)) dτ" | 같음 | 같음 |

원인: Word로 옮기는 변환기가 아래첨자로 처리하는 문자 목록에 τ가 빠져 있었다. 다른 아래첨자(r_t, σ_t, α_t 등)는 정상이다.

## 5. 본문

- **원문자 나열 11곳:**
  - 3.2.1 특성 설명 ①②③
  - 4.2 표 4-1 해석 ①②③
  - 6.3 비교 ①②
  - 3.1·3.5 표 안 ①②

- **문장 속 화살표 11곳:**
  - 2.1.1 "ν → ∞": 수식이라 유지
  - 4.1 "(79.31% → 79.31%)" → "(대체 전후 모두 79.31%)"
  - 5.3 "(80.0 → 77.5%)" 등 3곳 → "(80.0%에서 77.5%로)"
  - 5.4 3곳 → 같은 방식
  - 5.5.3 1곳 → 같은 방식
  - 6.2 "(… 0.84~1.19배 → 0.90~1.27배)" → "(0.84~1.19배에서 0.90~1.27배로)"
  - 부록 A 3곳: A.1 일정의 "→"는 순서 나열이라 쉼표로, A.4 2곳은 "에서 ~로"로
