# 제1장 서론

## 1.1 연구 배경

시계열 파운데이션 모델(time series foundation model, TSFM)은 대량의 시계열로 미리 학습해 두고, 새로운 데이터에는 추가 학습 없이 바로 예측을 내는 모델이다. Chronos, TimesFM, Moirai 같은 모델이 2024년 이후 잇달아 공개되었고, 최근에는 Chronos-2, TimesFM-2.5, Moirai-2.0으로 개선판이 나왔다. 이 모델들은 숫자 하나(점 예측)만이 아니라 "내일 값이 이 범위에 80% 확률로 들어간다" 같은 예측구간, 즉 확률 예측을 함께 낸다.

금융에서 예측구간은 점 예측보다 쓰임이 많다. 주가 수익률의 방향은 거의 예측할 수 없지만, 내일 얼마나 크게 움직일지는 어느 정도 예측할 수 있고, 이것이 위험 한도(VaR), 포지션 크기 조절, 손절 기준 같은 실무 위험 관리의 기초가 된다. 이때 중요한 것은 구간이 명목 수준을 충족하는가이다. 80% 구간이라고 했으면 실제로 열 번 중 여덟 번은 그 안에 들어와야 한다. 들어오는 비율(커버리지)이 60%라면 위험을 과소평가한 것이고, 95%라면 쓸데없이 보수적인 것이다.

그런데 금융 분야의 TSFM 연구는 주로 점 예측의 정확도를 비교해 왔다. Rahimikia 외(2025)는 여러 나라의 일별 주식 수익률에서 Chronos·TimesFM을 그대로 쓰면 성과가 나쁘다고 보고했고, Noguer i Alonso와 Franklin(2026)은 미국 대형주 5종목에서 TSFM이 처음부터 학습한 신경망보다 대체로 낫지만 랜덤워크 대비 이득은 작다고 보고하였다. 두 연구 모두 예측구간의 커버리지는 평가하지 않았다. 한편 FinStressTS(Sun 외, 2026)는 금융 특성을 하나씩 조절한 합성 데이터로 예측 모델의 약점을 진단하는 방법을 제시했지만, 사전학습 TSFM의 제로샷 예측구간을 대상으로 하지는 않았다.

따라서 사전학습 TSFM의 금융 예측구간이 명목 커버리지를 충족하는지, 미달 또는 초과가 발생한다면 그 원인이 금융 시계열의 고유 특성(변동성 군집, 두꺼운 꼬리, 국면 전환)에 있는지 혹은 모델 및 입력 설정에 있는지, 나아가 재학습 없는 사후보정으로 이를 교정할 수 있는지에 대해서는 체계적인 검증이 필요한 시점이다.

## 1.2 연구 질문

본 연구는 세 질문에 답한다.

- **RQ1 (진단)**: 금융 데이터의 특성(변동성 군집, 두꺼운 꼬리, 국면 전환의 빈도와 크기)이 강해질수록 TSFM 80% 예측구간의 커버리지가 떨어지는가, 아니면 모델과 입력 설정에서 이미 오차가 발생하는가? 특성 중에서는 어떤 것이 가장 불리한가?
- **RQ2 (실증 평가)**: 실제 미국·한국 대형주에서 TSFM 예측구간의 커버리지와 분포 정확도는 어떠하며, 단순 기준 모형(과거 변동성 기반 정규분포, RW)보다 나은가?
- **RQ3 (처방)**: 모델을 재학습하지 않는 온라인 사후보정(ACI-CQR)으로 커버리지를 80%로 복원할 수 있는가? 그 대가는 무엇인가?

## 1.3 연구 방법 개요

RQ1은 합성 데이터 실험으로 답한다. 실제 10종목에서 측정한 특성 강도를 기준치로 삼아 합성 데이터 17개 시나리오(특성 없음 1개 + 4개 특성 × 4단계)를 만들고, 같은 난수와 같은 평균 변동 크기를 쓰되 특성 하나만 바꾸어 그 영향을 분리하였다. 데이터를 만든 참 분포를 알기 때문에 오라클 모형으로 채점 절차를 검증할 수 있다.

RQ2는 실제 주가 실증으로 답한다. 미국 5종목(AAPL, AMZN, GOOG, JPM, META)과 한국 5종목(삼성전자, SK하이닉스, 현대차, 한국전력, 현대모비스)의 2017년 1월~2026년 9월 매 거래일에 대해 다음 날 로그수익률의 분포를 예측하였다(24,132건).

두 환경 모두 같은 절차를 쓴다. TSFM 4종(Chronos-T5, Chronos-2, TimesFM-2.5, Moirai-2.0)을 과거 길이 2가지(21일, 252일) × 입력 형태 2가지(수익률, 가격) = 4개 조건에서 평가하고, RW와 GARCH(1,1)-t를 기준 모형으로 둔다. RQ3은 두 환경 모두에 같은 사후보정을 적용해 답한다.

실험 설정, 가설, 판정 기준, 분석 코드는 실행 전에 git 커밋으로 동결하였다(사전등록). 동결 후의 변경과 실행 중 발견한 사항은 모두 기록하여 밝힌다.

## 1.4 주요 결과와 기여

본 연구의 주요 결과는 다음과 같다.

1. **오차의 출처는 금융 특성보다 모델과 입력 설정이다.** 특성이 전혀 없는 데이터에서 이미 TSFM의 80% 구간 커버리지는 14%에서 88%까지 퍼져 있었고, 특성을 실제 종목 중 가장 강한 수준(L5)으로 설정해도 대부분 3%p 이내로만 움직였다. 꼬리와 잦은 국면 전환은 오히려 커버리지를 높였다. 실제 주가의 커버리지는 특성 없는 합성 데이터의 커버리지와 평균 1.0%p (구간이 붕괴한 Chronos-T5 수익률 2개 조건 제외, 19개 전체는 1.2%p) 차이였다.
2. **정확도는 단순 기준 모형을 넘지 못한다.** 실제 주식에서 분위수 손실은 16개 조건 중 13개에서 RW보다 나빴고, 가장 좋은 조건도 RW와 같은 수준이었다.
3. **사후보정은 모든 경우에 80%를 복원한다.** 합성 340개, 실제 19개 모델·조건에서 예외가 없었다. 대가는 구간 폭이며, 보정된 구간은 이상적인 구간보다 6~48% 넓었다.

이를 바탕으로 한 본 연구의 기여는 다음과 같다.

- **방법론**: 실제 종목에서 측정한 특성 강도로 합성 데이터의 강도 단계를 설정하고, 공통 난수로 특성 하나씩만 바꾸는 통제 실험을 TSFM 예측구간 진단에 적용하였다. 이 설계는 합성 데이터 실험의 결과가 실제 주가와 연결되는지를 직접 확인할 수 있게 해 준다(5.4절).
- **실증**: 최신 TSFM 4종을 두 시장, 약 10년, 4개 사용 조건에서 사전등록 절차로 평가하고, 결과를 선택하지 않고 전체 표로 보고하였다.
- **실무**: TSFM 예측구간을 위험 관리에 쓸 때 입력 설정 점검과 사후보정이 필요함을 보이고, 이것이 변동성 목표·VaR 같은 실제 의사결정에 어떤 차이를 만드는지 탐색하였다(5.5절).

## 1.5 논문 구성

제2장은 관련 연구를 정리한다. 제3장은 연구 설계를, 제4~6장은 RQ1~RQ3의 결과를 차례로 다룬다. 제7장은 결론과 한계, 향후 연구를 제시한다.
