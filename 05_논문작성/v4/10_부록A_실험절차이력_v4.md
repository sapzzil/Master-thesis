## A.2 동결과 이탈 기록

- 일정: 설계 확정·단계값 측정·사전 시험(2026-10-13) → 동결 커밋 `8f55c57`(2026-10-14 01:43 KST) → 본 실행(GPU 추론, 01:44~07:06, 약 5.4시간) → 독립 검산 및 분석.
- 동결 후의 변경은 사전등록 프로토콜의 이탈 기록 절차(변경 사유 기록과 새 커밋)로만 허용하였다.
- 동결 전 사전 시험: 실제 GPU 환경과 같은 패키지 버전으로 전체 규모를 시험하였다. 이때 TSFM 대신 더미(dummy) 모델을 사용하였으나, 기준 모형(RW, GARCH-t)은 실제 모델이므로 실제 주가에 대한 기준 모형 결과(커버리지 등)가 시험 출력에 함께 산출되었다. 이를 본 뒤 설정과 코드는 바꾸지 않았고, 본 실행에서 같은 값을 다시 계산하였다.
- 사후 발견: GARCH-t 합성 2건(전환크기 L3 계열 79의 66일째, 꼬리 L2 계열 86의 64일째)이 사전 대체 규칙(유한값 아님, 분산 ≤ 0, ν ≤ 2)에 걸리지 않는 비정상 값을 냈다. 민감도는 6.5절.
