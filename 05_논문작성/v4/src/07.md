# 제7장 결론

## 7.1 연구 요약

본 연구는 사전학습 시계열 모델(TSFM)이 내는 금융 수익률 80% 예측구간이 약속을 지키는지, 지키지 못한다면 원인이 무엇이고 어떻게 고칠 수 있는지를 실측 기반 합성 통제 실험과 미국·한국 대형주 10종목 평가로 검증하였다. 표 7-1은 세 연구 질문에 대한 답을 정리한다.

**표 7-1. 연구 질문별 결과**

| 연구 질문 | 가설 | 결과 | 핵심 근거 |
|---|---|---|---|
| RQ1 진단 | H1 군집 → 하락 | 일부 지지(16개 중 2개 조건 실질 하락) | −2.0~−2.5%p |
| | H2 꼬리 → 하락 | 미지지, 반대 방향(9개 조건 유의한 상승) | 정규 80% 구간의 t분포 커버리지 82~87% |
| | H3a 전환 빈도 → 하락 | 미지지(5개 조건 작은 상승) | 혼합분포 효과 |
| | H3b 전환 크기 → 하락 | 미지지 | 유의한 변화 1개(작은 상승) |
| | H4 축마다 다름 | 16개 중 9개 지지, 모두 군집이 가장 불리 | Friedman, Holm 보정 |
| RQ2 현실 평가 | H6 TSFM이 RW보다 정확 | 미지지(13개 열위, 2개 차이 없음, 1개 작은 우위) | 분위수 손실 −19.5~+0.9% |
| RQ3 처방 | H5 보정 후 80% 복원 | 전면 지지(합성 340개, 실제 19개) | 보정 후 79.7~80.7% |

세 결과를 하나로 묶으면 다음과 같다. **TSFM 예측구간의 오차는 크고 모델·설정마다 방향도 다르지만, 그 오차의 대부분은 금융 데이터의 특성이 아니라 모델과 입력 설정에서 오며, 재학습 없는 사후보정으로 일관되게 바로잡힌다. 다만 분포의 정확도 자체는 과거 변동으로 그린 단순 정규분포(RW)를 넘지 못한다.**

## 7.2 실무적 시사점

1. **입력 설정을 먼저 점검해야 한다.** 같은 모델이라도 수익률을 넣느냐 가격을 넣느냐, 과거를 얼마나 보여 주느냐에 따라 커버리지가 15%에서 88%까지 달라졌다(Chronos-T5 수익률 15% 대 가격 76%, TimesFM-2.5 1년·가격 88% 대 1년·수익률 77~79%). 특성이 없는 합성 데이터에서 커버리지를 미리 재 보면 실제 주가에서의 커버리지를 평균 1%p 차이로 예측할 수 있었다(5.4절). 즉 실제 데이터에 쓰기 전에 간단한 점검으로 잘못된 설정을 걸러낼 수 있다.
2. **사후보정을 기본으로 붙여야 한다.** ACI-CQR은 모델을 바꾸지 않고, 계산 비용이 거의 없으며, 모든 경우에 80%를 복원하였다. 변동성 목표와 VaR 같은 실제 규칙에서도 보정 전후의 차이가 분명했다(5.5절, 6.6절).
3. **정확도에 대한 기대는 단순 기준 수준으로 잡아야 한다.** 일별 수익률에서 TSFM은 RW보다 나은 분포를 내지 못했고, 방향을 맞혀 수익을 내는 규칙도 계속 보유보다 못했다. TSFM 예측구간의 쓸모는 방향 예측이 아니라 **위험 크기 측정**에 있으며, 그것도 보정을 거쳤을 때 의도대로 작동한다.

## 7.3 한계

1. **80% 구간만 평가하였다.** 일부 모델이 0.1~0.9 분위수만 내기 때문에 99%·95% 같은 극단 구간은 평가하지 못했다. 4.3절에서 보였듯 꼬리가 두꺼울수록 80% 구간은 넓어지지만 극단 구간은 반대로 좁아질 수 있으므로, 본 연구의 "꼬리는 불리하지 않다"는 결과를 극단 위험에 그대로 적용해서는 안 된다.
2. **다음 날 예측만 다루었다.** 여러 날 앞 예측에서는 오차 누적과 군집의 영향이 다르게 나타날 수 있다.
3. **대상이 대형주 10종목이다.** 2017년 기준 미국·한국 대형주이며, 소형주, 다른 자산(채권, 환율, 암호화폐), 다른 시장으로의 일반화는 확인하지 않았다. 미국 종목은 기준 연구 재현을 위해, 한국 종목은 시가총액 순위로 골라 선정 방식이 다르다.
4. **합성 눈금은 대형주 기반이다.** 단계값을 대형주 10종목에서 측정했으므로, 특성이 더 극단적인 자산에서는 효과가 더 클 수 있다. 또한 특성을 하나씩만 바꾸었으므로 특성 간 상호작용은 실제 데이터로 간접 확인하는 데 그쳤다.
5. **모델 구성.** Chronos-T5는 계산 시간 규칙에 따라 large 대신 base를 썼고, Moirai-2.0은 small 크기만 평가하였다. 미세조정이나 금융 데이터로 사전학습한 모델은 다루지 않았다.
6. **보정의 범위.** 보정은 80% 구간의 양 끝만 조정하므로 분포 전체의 정확도를 높이지 않으며, 위반이 몰려 오는 문제(한 달·가격 조건)는 고치지 못했다. 또한 사후 배율로 일괄 확대한 대조군보다 폭 효율이 낮았다.
7. **경제적 가치 분석은 탐색적이다.** 사전등록 밖의 분석이며, 전날 종가 체결과 단순한 비용 가정을 썼고, 표본 기간이 강세장을 포함한다.

## 7.4 향후 연구

1. 극단 분위수(1%, 5%)를 내는 모델과 설정에서 꼬리 특성의 영향 재검증
2. 여러 날 앞 예측과 다른 자산군으로의 확장
3. Chronos-T5 수익률 입력의 구간 붕괴 원인(입력 크기 조정·구간화 방식) 규명
4. 보정의 폭 효율 개선: 갱신 속도(γ)의 적응적 조정, 변동 크기에 따른 조건부 보정, 위반 몰림을 줄이는 방법
5. 금융 데이터로 미세조정·사전학습한 모델과의 비교(Rahimikia 외, 2025의 방향)

## 7.5 맺음말

새로운 예측 모델을 금융에 쓸 때 흔히 "얼마나 정확한가"를 먼저 묻는다. 본 연구의 결과는 그보다 먼저 "약속한 만큼 맞는가"를 물어야 하며, 그 답은 모델의 성능보다 우리가 모델을 어떻게 쓰는가에 더 크게 달려 있음을 보여 준다. 사전학습 모델의 예측구간은 그대로 믿을 것이 아니라, 설정을 점검하고 보정을 거쳐 쓰는 도구다.
