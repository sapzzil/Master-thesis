### D-2. 용어 정의와 근거

| 용어 | 영문 | 뜻 (초안) | 왜 썼나 / 근거 |
|---|---|---|---|
| TSFM | time series foundation model | 대량의 시계열로 미리 학습해, 새 데이터에 추가 학습 없이 점 예측과 함께 분위수(분포)를 내는 모델. Chronos, TimesFM 등 | Ansari 외(2024) 등 각 모델 논문 |
| 예측구간 | prediction interval | 실제값이 정해진 확률로 들어올 것이라고 모델이 낸 범위. 본 연구는 0.1·0.9 분위수 사이 = 80% 구간 | Gneiting 외(2007) |
| 분위수 | quantile | p 분위수 = 실제값이 그보다 낮을 확률이 p인 값 | |
| 명목 커버리지 | nominal coverage | 구간이 약속한 확률(80%) | |
| 커버리지 | (empirical) coverage | 실제값이 구간 안에 들어간 날의 비율 | Christoffersen(1998) 구간 예측 평가 |
| 캘리브레이션 | calibration | 모델이 말한 확률과 실제 비율이 일치하는 성질 | Gneiting 외(2007) |
| 캘리브레이션 오차 | calibration error | 커버리지 − 명목 커버리지. 본 연구는 80% 구간 한 수준에서 잼 | [추가][확인] Kuleshov 외(2018) 회귀 캘리브레이션 |
| 구간 폭 | sharpness | 같은 커버리지면 좁을수록 좋음 | Gneiting 외(2007) |
| 분위수 손실 | quantile (pinball) loss | 0.1~0.9 분위수 9개가 실제값에서 얼마나 떨어졌는지의 평균. 분포 전체의 정확도 | Gneiting·Raftery(2007) |
| VaR 10% | value at risk | 다음 날 수익률이 그보다 낮을 확률이 10%인 값 = 80% 구간의 하단 | |
| 위반율 / Kupiec 검정 | violation rate / unconditional coverage test | 실제 수익률이 VaR보다 낮았던 날의 비율, 그 비율이 10%인지 검정 | Kupiec(1995) |
| Christoffersen 검정 | independence test | 위반이 특정 시기에 몰리는지 검정 | Christoffersen(1998) |
| 콘포멀 예측 | conformal prediction | 과거 예측이 실제값에서 벗어난 정도로 구간을 조정해, 분포 가정 없이 커버리지를 맞추는 방법 | Vovk 외(2005) |
| CQR | conformalized quantile regression | 모델이 낸 분위수 구간의 양 끝을 콘포멀 방식으로 넓히거나 좁힘 | Romano 외(2019) |
| ACI | adaptive conformal inference | 최근 이탈 기록에 따라 목표 수준을 매일 바꿔, 분포가 변해도 장기 평균 커버리지를 맞춤 | Gibbs·Candès(2021) |
| 오라클 | oracle | 데이터를 만든 참 분포로 낸 구간. 합성 데이터에만 있음 | |
| RW | historical-volatility Gaussian | 과거 L일 수익률의 평균·표준편차로 만든 정규분포 | |
| GARCH-t | GARCH(1,1) with Student-t | 변동성 군집과 두꺼운 꼬리를 표현하는 계량 모형 | Bollerslev(1986), t분포 오차는 [추가][확인] |
| 공통 난수 | common random numbers | 모든 시나리오가 같은 난수를 써서 특성 설정만 다르게 함 | |
| Holm 보정 | Holm correction | 여러 검정을 동시에 할 때 유의수준 조정 | Holm(1979) |
