### ✅ 잔여 확인 완료 (2026-08-12, 2단계 착수 세션)
1. **Brini Appendix C.1 "Drivers of Forecast Performance" 확인 완료** — 원문 대조 결과, 실측 50개
   자산의 1차 자기상관(ρ1) vs QLIKE 비율 간 **사후 상관분석**(대부분 모델에서 상관 미약·유의성 없음).
   통제된 실험이 아니라 실데이터 횡단면 상관 확인 수준 → 우리의 파라메트릭 통제실험과 성격이 다름.
   **위험 해소.**
2. **Brini §8 Conclusion / §7 Context-length sensitivity(Appendix B Table 14) 확인 완료** — TTM만
   모든 horizon에서 Log-HAR를 근소하게 이김, 나머지 8개 TSFM은 못 이김. Context-length 민감도는
   모델별로 다르지만 "TTM만 승리"라는 결론 자체는 불변. CRPS·캘리브레이션 논의 없음 → 차별점 유지.
3. **Re(Visiting) §5.3 International Results 확인 완료** — 한국(KOR)은 7개 국제시장 중 하나로
   포함되어 있으나, **벤치마크 모델·TSFM 모두에서 대만과 함께 "가장 어려운 환경"으로 명시됨**
   (앙상블 평균 Sharpe ≈0.20, 증강 후에도 개선 미미). 한국 단독 최초 적용 주장은 여전히 금지지만,
   "한국 시장이 TSFM에 특히 취약하다"는 근거로는 인용 가능.
4. **Re(Visiting) §6 Conclusion 확인 완료** — **"TSFM은 본질적으로 전체 예측분포를 생성할 수 있고,
   향후 연구가 고차 통계량(higher-order statistics)을 탐구할 수 있다"고 향후연구로 명시적으로 남김.**
   → CRPS·캘리브레이션 공백을 우리가 메운다는 차별점을 저자 스스로 인정한 것으로 인용 가능(강한 근거).
5. **Re(Visiting) Appendix D 확인 완료** — TSFM 모델 요약/용어집 수준. 리스크 없음.

## 사후 보정 방법론 방향 (확정)

LoRA 등 파인튜닝 방식 대신 **콘포멀 예측(conformal prediction)/분위수 보정(quantile calibration)** 같은
**사후(post-hoc) 보정**으로 방향을 잡음.
- 이유: 모델 가중치를 안 건드려 GPU 부담이 적고, "LoRA가 금융에서 오히려 성능을 떨어뜨린다"는 기존
  문헌 리스크와도 무관함. 모델 자체는 얼려두고(frozen) 출력값에 보정 함수만 사후 적용.
- 참고 문헌(정식 2~3단계 아직 미착수, 초록 수준만 확인): δ-Adapter(arXiv 2601.20280, ICLR 2026),
  GLCP(arXiv 2607.23165)
- 용어집에 "콘포멀 예측" 항목 추가 예정 (`claude_용어집.md` 참조)
