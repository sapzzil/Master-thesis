# v4 사후 점검 지시서 (2026-10-20) — Antigravity 실행용

## 목적

본 실행이 끝난 뒤 디펜스 대비로 세 가지를 추가로 확인합니다. 미리 고정한 분석 계획 밖의 점검이며, 결과가 어떻게 나오든 모두 그대로 보고합니다.

- e1: Chronos-T5가 수익률 입력에서 구간이 붕괴한 원인(샘플링 설정 top_k, 값 크기)
- e2: Chronos-2에 거래량을 함께 넣으면 달라지는지(실제 10종목)
- e3: TimesFM-2.5의 1년·가격 구간 과대 원인(분위수 출력 방식, 입력 정규화, 로그 가격)

**결과를 해석하거나 논문을 고치지 않습니다.**

## 규칙

1. 새 코드는 `04_실험코드/src_v4_post/post_checks_v4.py` 하나뿐입니다. 이 파일과 `src_v4/` 등 기존 코드는 고치지 않습니다. 오류가 나면 우회하지 말고 멈춘 뒤 오류 메시지를 그대로 보고합니다.
   - 예외: 스모크에서 모델 호출부(e1의 `fc`, e2의 `fc`, e3의 `fc`·`get` 함수 안쪽) 오류가 나면 그 함수 안쪽만 고칠 수 있습니다. 고쳤다면 전후 코드와 이유를 보고하고, Claude 확인 전에는 본 실행으로 넘어가지 않습니다.
2. 기존 결과(`results_v4/`, `data/`)는 읽기만 합니다. 새로 생기는 것은 `results_v4_post_smoke/`, `results_v4_post/`, 그리고 `04_실험코드/` 바로 아래의 로그 파일(`post_*.txt`)뿐입니다.
3. 환경은 `thesis_v4` 그대로 씁니다. 패키지를 설치하거나 업그레이드하지 않습니다.
4. 모든 명령은 `04_실험코드/src_v4_post/` 폴더에서 실행합니다.

## 0. 준비

```
conda activate thesis_v4
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING="utf-8"
cd 04_실험코드\src_v4_post
Get-FileHash post_checks_v4.py -Algorithm SHA256 | Format-Table Hash -AutoSize
```

지문을 보고에 적습니다.

## 1부. 스모크 (약 5분) — 끝나면 보고하고 멈춤

```
python post_checks_v4.py --exp e1 --smoke 2>&1 | Tee-Object -FilePath ..\post_smoke_e1.txt
python post_checks_v4.py --exp e2 --smoke 2>&1 | Tee-Object -FilePath ..\post_smoke_e2.txt
python post_checks_v4.py --exp e3 --smoke 2>&1 | Tee-Object -FilePath ..\post_smoke_e3.txt
```

- 각 명령이 `[요약]` 표를 출력하고 `[완료]`로 끝나야 합니다.
- e1 첫머리의 `[설정] Chronos-T5 base: ...` 줄을 그대로 보고에 넣습니다.
- e2 스모크의 요약 표에서 `share_changed` 값을 확인합니다. 0이면 거래량이 모델에 전달되지 않은 것이므로 멈추고 보고합니다.
- 숫자는 해석하지 않습니다.

### 1부 보고 양식

```
[0] post_checks_v4.py 지문
[e1] post_smoke_e1.txt 전체
[e2] post_smoke_e2.txt 전체
[e3] post_smoke_e3.txt 전체
[기타] 고친 부분이 있으면 전후 코드와 이유, 막힌 것
```

**여기서 멈추고 Claude의 확인을 기다립니다.**

## 2부. 본 실행 (Claude가 "진행"이라고 한 뒤에만)

```
python post_checks_v4.py --exp e3 2>&1 | Tee-Object -FilePath ..\post_e3.txt
python post_checks_v4.py --exp e2 2>&1 | Tee-Object -FilePath ..\post_e2.txt
python post_checks_v4.py --exp e1 2>&1 | Tee-Object -FilePath ..\post_e1.txt
```

| 점검 | 예상 시간 |
|---|---|
| e3 TimesFM | 5분 안팎 |
| e2 Chronos-2 | 10분 안팎 |
| e1 Chronos-T5 | 약 1시간(예측 약 10만 회) |

- 중간에 끊기면 같은 명령을 다시 실행합니다. 이미 저장된 결과는 건너뜁니다.
- 각 실행 끝의 `[재현 확인]` 줄은 기본 설정 결과가 본 실행과 같은지 보는 것입니다. 차이가 1%p를 넘으면 보고에 표시합니다.

### 2부 보고 양식

```
[e1] post_e1.txt의 [설정]·[저장]·[요약]·[재현 확인] 줄 전체
[e2] post_e2.txt의 [저장]·[요약]·[재현 확인] 줄 전체
[e3] post_e3.txt의 [저장]·[요약]·[재현 확인] 줄 전체
[파일] results_v4_post/summary_e1.csv, summary_e2.csv, summary_e3.csv 생성 여부
[기타] 오류, 경고, 막힌 것
```

결과 파일은 Claude가 저장소에서 직접 읽어 검증합니다. 커밋은 하지 않습니다.
