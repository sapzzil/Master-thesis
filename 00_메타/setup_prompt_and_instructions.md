# 논문 프로젝트 세팅 — 재사용 프롬프트 & 지침

> 새 논문 프로젝트를 시작하거나, 연구주제가 완전히 바뀌어 처음부터
> 다시 세팅할 때 이 파일의 [세팅 프롬프트]를 그대로 복사해서 새 대화에
> 붙여넣으면 됩니다. [Custom Instructions]는 claude.ai Projects 탭
> 설정에 붙여넣는 별도 텍스트입니다.

---

## 1. 세팅 프롬프트 (새 대화에 붙여넣기용)

```
석사논문 작업용 파일 세팅을 만들어줘. 아래 원칙을 반드시 지켜서 설계해줘.

[입력값]
- 로컬 작업 폴더 경로: [ ]
- Google Drive 백업 폴더 링크: [ ]
- 연구주제 대분야 (미정이면 "미정"이라고): [ ]
- 현재 진행 단계 (1~7단계 중): [ ]

[설계 원칙 - 반드시 지킬 것]
1. "현재 상태"(주제, 단계, 다음할일)는 진행상황.md 한 곳에만 쓰고,
   다른 어떤 파일에도 중복 기재하지 마. CLAUDE.md는 순수 구조/경로/
   실행규칙 전용으로 만들고, 현재상태는 진행상황.md를 참조하라고만 적어.
2. 결정로그.md는 append 전용 이력 파일로 따로 만들어 (지우지 않고 쌓임).
3. 워크플로우 구조 문서는 "순차 단계"와 "지속 트랙"(버전관리·일정관리·
   레퍼런스관리·표절점검·재현성문서화처럼 특정 단계에 속하지 않고
   전체 기간 병행되는 것들)을 명확히 분리해서 만들어. 지속 트랙을
   단계 번호에 억지로 끼워넣지 마.
4. 각 순차 단계마다 권장 도구(Chat/Cowork/Claude Code 중 어디),
   모델(Haiku/Sonnet/Opus), effort(low~high), 서브에이전트 병렬화
   가능 여부와 나누는 기준(단순 물량 분할이 아니라 의미 있는 하위
   갈래/독립 실험 단위)까지 표로 넣어줘.
5. claude.ai Projects 지식 파일과 로컬 파일은 자동 동기화되지 않는다는
   전제로 설계해. Claude Code/Cowork가 직접 쓸 수 있는 로컬 파일
   (CLAUDE.md, 결정로그.md)은 세션 종료 시 자동 갱신되도록 규칙을
   넣고, 클라우드 파일(진행상황.md 사본)은 사람이 수동 재업로드해야
   한다는 걸 CLAUDE.md 안에 명시해.
6. GitHub는 "커넥터(읽기·컨텍스트용, 아무 모드에서나)"와 "로컬 Git
   워크플로우(실제 push/pull, Cowork나 Claude Code가 실행)"를 구분해서
   설명하고, 후자를 기준으로 CLAUDE.md의 git 관련 규칙을 작성해.
7. 로컬 폴더 하위구조(00_메타/01_자료원문/02_요약정리/03_최종취합/
   04_실험코드/05_논문작성/06_예상질문_방어논리/07_부가작업)를 만들고,
   CLAUDE.md에 각 폴더 규칙을 명시해.
8. 파일 간 상호 참조는 정확해야 해 — 특정 산출물(예: 선행연구_종합.md)을
   "몇 단계 이후부터 존재"라고 적을 땐, 워크플로우 구조표에서 그 산출물이
   실제로 어느 단계의 결과물인지 반드시 대조해서 맞는 단계 번호를 적어.
   추측하거나 인접한 단계 번호를 임의로 쓰지 마.
9. [입력값]으로 이미 확정해서 받은 정보(로컬 경로, Drive 링크 등)는
   "이미 완료된 것"으로 취급해. 진행상황.md의 "다음 할 일"에 이미
   확정된 항목을 "생성/설정해야 함"으로 다시 넣지 마 — 저장 위치 섹션과
   다음 할 일 섹션이 서로 모순되지 않도록 교차 확인해.
10. 모든 파일을 생성한 뒤, 파일들을 다시 한번 읽어서 (a) 파일명·단계번호
    참조가 실제 구조와 일치하는지, (b) 섹션 간 모순이 없는지, (c) 이전에
    쓰다가 이름이 바뀐 파일을 가리키는 낡은 참조가 남아있지 않은지
    자체 검증하고, 발견된 문제는 산출물 제시 전에 미리 고쳐서 줘.

[산출물]
- CLAUDE.md
- 결정로그.md
- 진행상황.md
- 논문_워크플로우_구조.md
- Projects 탭 Custom Instructions에 붙여넣을 짧은 텍스트 (3줄 이내)

각 파일을 실제로 생성해서 다운로드 가능하게 주고,
어디에 어떻게 배치하는지 표로 요약해줘.
```

## 2. Custom Instructions (claude.ai Projects 탭 설정에 붙여넣기용)

```
이 프로젝트는 순차 7단계 + 지속 트랙 구조의 논문 워크플로우를 따릅니다.
답변 전 항상 지식(Knowledge)의 논문_워크플로우_구조.md와 진행상황.md를
참조해서 현재 어느 단계인지, 확정된 내용이 무엇인지 파악한 후 답변하세요.
```
