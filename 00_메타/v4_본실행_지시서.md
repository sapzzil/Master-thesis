# v4 본 실행 지시서 (2026-10-14) — Antigravity 실행용

## 목적

v4 사전등록 실험을 PC(RTX 3080)에서 실행합니다. 순서는 두 단계입니다.

1. **1부 스모크**: 작은 규모로 실제 모델을 돌려 봅니다(약 15분). 결과는 보고만 하고 **멈춥니다**.
2. **2부 동결·본 실행**: Claude가 스모크를 검토해 "진행"이라고 하면 동결 커밋을 하고 전체를 실행합니다(약 7~8시간).

**결과를 해석하거나 논문을 고치지 않습니다.**

## 규칙

1. 코드(`04_실험코드/src_v4/`)는 고치지 않습니다. 오류가 나면 우회하지 말고 멈춘 뒤 오류 메시지를 그대로 보고합니다.
   - 예외: 스모크에서 모델 호출부(어댑터 클래스 안쪽) 오류가 나면 그 클래스 안쪽만 고칠 수 있습니다. 고쳤다면 전후 코드와 이유를 보고하고, Claude 확인 전에는 2부로 넘어가지 않습니다.
2. 기존 파일은 수정·삭제하지 않습니다: `src`, `src_v3`, `src_v4_prep`, `results_v3`, `data/raw`, `data/raw_v4`.
   - 새로 생기는 것은 `data/synthetic_v4/`, `results_v4_smoke/`, `results_v4/`, 그리고 `04_실험코드/` 바로 아래의 로그 파일(`smoke_*.txt`, `results_v4_log_*.txt`)뿐입니다.
3. 환경은 `thesis_v4` 그대로 씁니다. 패키지를 설치하거나 업그레이드하지 않습니다.
4. `results_v4/` 안의 파일을 손으로 지우거나 옮기지 않습니다. 이어서 실행하는 기능이 이 파일들을 기준으로 동작합니다.
5. 모든 명령은 `04_실험코드/src_v4/` 폴더에서 실행합니다.

## 1부. 스모크 (약 15분) — 끝나면 보고하고 멈춤

```
python 01_generate_synthetic_v4.py 2>&1 | Tee-Object -FilePath ..\results_v4_log_01.txt
```

- 첫 줄에 `[점검] 네 축의 L1 모수로 만든 데이터가 L1과 동일: 통과`가 나와야 합니다.


**예상 시간**

| 모델 | 예상 |
|---|---|
| Moirai | 수 분 |
| TimesFM | 15분 |
| Chronos-2 | 5분 |
| RW | 1분 미만 |
| GARCH | 10~60분 (CPU 코어 수에 따라) |
| Chronos-T5 base | 약 6시간 (스모크 실측 기준) |
| 03 + 07 | 10~20분 |

- 진행률(%)과 남은 예상 시간이 계속 출력됩니다.
- **끊겼을 때**(정전, 오류, 실수로 종료): 같은 명령을 다시 실행하면 이미 끝난 조건은 `[건너뜀]`으로 넘어가고 이어서 진행합니다. 처음부터 다시 돌리지 않습니다.
- **멈춤 기준**: 한 모델에서 진행률 줄이 30분 넘게 안 바뀌면 Ctrl+C로 멈추고 보고합니다. 작업관리자의 GPU 전용·공유 메모리 화면도 함께 보고합니다.
- `GPU 메모리 … → 이후 배치 …` 또는 `메모리 부족 → 배치 …로 줄여 계속` 줄은 정상입니다. 결과 값에는 영향이 없습니다.
- 오류로 멈추면 다음 모델로 넘어가지 말고 보고합니다.
