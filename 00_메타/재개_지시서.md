## 이번 세션 할 일

### 5단계 착수 — 가설·실험·검증 코드
워크플로우 문서 기준: **Claude Code 필수(실행·검증 루프 핵심). 설계는 Opus·high effort, 구현·
반복 실행은 Sonnet·medium effort. 독립적 실험(베이스라인 비교/하이퍼파라미터/ablation)은 병렬,
결과 해석은 순차 종합.**

**최우선 과제 (진행상황.md의 "남은 위험 1건")**: TSFM이 CRPS 계산에 쓸 만한 확률 예측을 실제로
내놓는지 파일럿으로 직접 확인. Chronos·Moirai는 분위수/샘플을 출력한다고 원문에서 확인했으나
실측 전. **이게 안 되면 핵심 지표가 사라지므로 반드시 첫 주에 확인.**

### 이번 단계에서 반드시 지킬 설계 원칙 (4단계에서 확정, `03_최종취합/관련연구_초안.md` 7절 참고)
1. **CRPS 계산 시 불편 추정량 사용**: FinStressTS의 `1/(2S²)` 대신 `1/(S(S−1))` — 하위갈래 B에서 발견
2. **누출 통제 대상을 Chronos에서 LOTSA 기반 모델 전체(Moirai 1.0/2.0, Moirai-MoE, Toto)로 확대**
   — 하위갈래 A에서 발견, 진행상황.md 리스크 3번 참고
3. **FinStressTS 생성기 재사용 시 T=2,000(논문) vs T=20,000(코드) 중 결정 필요**, Case 1(GARCH)의
   ceteris paribus가 실제로 깨져 있다는 점 통제 조건에 반영 — 하위갈래 C에서 발견
4. **캘리브레이션 평가는 PIT 단독 판정 금지** — CRPS(1차 랭킹) + PIT 히스토그램(진단) + 구간

   명시적 경고
