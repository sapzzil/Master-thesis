# v4 Chronos-T5 재실행 지시서 (2026-10-21) — Antigravity 실행용

## 목적

사후 점검(e1)에서 Chronos-T5의 수익률 입력 구간 붕괴가 기본 샘플링 설정(top_k=50) 때문임을 확인했습니다. 이 설정만 풀고(top_k=4,096) Chronos-T5의 수익률 조건 2개를 다시 예측한 뒤, 본 실행과 같은 채점·보정·분석을 그대로 돌립니다. 본 실행 결과는 그대로 두고, 이 결과는 사후 분석으로 따로 보고합니다.

**결과를 해석하거나 논문을 고치지 않습니다.**

## 규칙

1. 새 코드는 `04_실험코드/src_v4_post/post_t5fix_v4.py` 하나뿐입니다. 이 파일과 `src_v4/` 등 기존 코드는 고치지 않습니다. 오류가 나면 우회하지 말고 멈춘 뒤 오류 메시지를 그대로 보고합니다.
2. 기존 결과(`results_v4/`, `results_v4_post/`, `data/`)는 읽기만 합니다. 새로 생기는 것은 `results_v4_t5fix_smoke/`, `results_v4_t5fix/`, 그리고 `04_실험코드/` 바로 아래의 로그 파일(`t5fix_*.txt`)뿐입니다.
3. 환경은 `thesis_v4` 그대로 씁니다. 패키지를 설치하거나 업그레이드하지 않습니다.
4. 모든 명령은 `04_실험코드/src_v4_post/` 폴더에서 실행합니다.
5. `results_v4_t5fix/raw/` 안의 파일을 손으로 지우거나 옮기지 않습니다(이어서 실행하는 기능이 이 파일들을 기준으로 동작).

## 1부. 스모크 (약 5분) — 끝나면 보고하고 멈춤

```
python post_t5fix_v4.py infer --smoke    2>&1 | Tee-Object -FilePath ..\t5fix_smoke_infer.txt
python post_t5fix_v4.py assemble --smoke 2>&1 | Tee-Object -FilePath ..\t5fix_smoke_assemble.txt
python post_t5fix_v4.py score --smoke    2>&1 | Tee-Object -FilePath ..\t5fix_smoke_score.txt
python post_t5fix_v4.py analyze --smoke  2>&1 | Tee-Object -FilePath ..\t5fix_smoke_analyze.txt
```

- infer 첫머리에 `[설정] top_k: 기본 50 → 4096 (어휘 전체)`가 나와야 합니다.
- 네 명령 모두 `[완료]`로 끝나야 합니다. 숫자는 해석하지 않습니다.

### 1부 보고 양식

```
[0] post_t5fix_v4.py 지문
[infer] t5fix_smoke_infer.txt 의 [설정]·[저장]·[완료] 줄
[assemble] t5fix_smoke_assemble.txt 전체
[score] t5fix_smoke_score.txt 전체
[analyze] t5fix_smoke_analyze.txt 전체
[기타] 오류, 막힌 것
```

**여기서 멈추고 Claude의 확인을 기다립니다.**

## 2부. 본 실행 (Claude가 "진행"이라고 한 뒤에만)

```
python post_t5fix_v4.py infer    2>&1 | Tee-Object -FilePath ..\t5fix_infer.txt
python post_t5fix_v4.py assemble 2>&1 | Tee-Object -FilePath ..\t5fix_assemble.txt
python post_t5fix_v4.py score    2>&1 | Tee-Object -FilePath ..\t5fix_score.txt
python post_t5fix_v4.py analyze  2>&1 | Tee-Object -FilePath ..\t5fix_analyze.txt
```

| 단계 | 예상 시간 |
|---|---|
| infer (예측 약 32만 회) | 약 3시간 |
| assemble | 1분 미만 |
| score | 10~20분 |
| analyze | 수 분 |

- infer가 중간에 끊기면 같은 명령을 다시 실행합니다. 이미 저장된 파일은 건너뜁니다.

### 2부 보고 양식

```
[infer] t5fix_infer.txt 의 [설정]·[저장]·[완료] 줄
[assemble] t5fix_assemble.txt 전체
[score] t5fix_score.txt 전체
[analyze] t5fix_analyze.txt 전체
[파일] results_v4_t5fix/scored_v4.parquet, results_v4_t5fix/tables/ 생성 여부
[기타] 오류, 경고, 막힌 것
```

결과 파일은 Claude가 저장소에서 직접 읽어 검증합니다. 커밋은 하지 않습니다.
