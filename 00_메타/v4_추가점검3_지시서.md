# v4 추가 점검 3 지시서 (2026-10-21) — Antigravity 실행용

## 목적

Chronos-2가 직접 내는 극단 분위수(0.01~0.99)로 90%·98% 구간의 커버리지를 확인합니다(g1). 본 실행과 같은 과제·같은 모델 호출로 분위수 수준만 21개로 늘려 다시 예측합니다. 결과가 어떻게 나오든 모두 보고합니다.

**결과를 해석하거나 논문을 고치지 않습니다.**

이 PC는 본 실행(RTX 3080)과 다른 PC입니다. 그래서 먼저 환경을 점검하고(0), 스모크(1)에서 걸린 시간을 보고한 뒤 멈춥니다. 본 실행(2)은 확인을 받은 뒤 진행합니다.

## 규칙

1. 새 코드는 `04_실험코드/src_v4_post/post_checks3_v4.py` 하나뿐입니다. `src_v4/`의 설정·과제 코드를 불러 씁니다. 어떤 코드도 고치지 않습니다. 오류가 나면 우회하지 말고 멈춘 뒤 오류 메시지를 그대로 보고합니다.
2. 기존 결과는 읽기만 합니다. 새로 생기는 것은 `results_v4_post_smoke/`, `results_v4_post/` 안의 g1 파일(`raw/g1__*.parquet`, `summary_g1.csv`, `g1_repro.csv`, `run_log.jsonl`에 덧붙는 줄)과 `04_실험코드/` 바로 아래의 로그 파일(`post3_*.txt`)뿐입니다.
3. 패키지를 설치하거나 업그레이드하지 않습니다. 환경이 맞지 않으면 0에서 멈추고 보고합니다.
4. 모든 명령은 `04_실험코드/src_v4_post/` 폴더에서 실행합니다.

## 0. 환경 점검 (GPU 안 씀, 1분 이내)

```
conda activate thesis_v4
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING="utf-8"
cd 04_실험코드\src_v4_post
Get-FileHash post_checks3_v4.py -Algorithm SHA256 | Format-Table Hash -AutoSize
python post_checks3_v4.py env 2>&1 | Tee-Object -FilePath ..\post3_env.txt
```

- 지문이 `EB53DAC9A2AB396BF07EAFB37B06AC221B41AB241EF5CBEB697C07521E37DBE0`인지 확인합니다. 다르면 멈추고 보고합니다.
- `thesis_v4` 환경이 없으면 멈추고 보고합니다(새로 만들지 않습니다).
- 출력에서 다음을 확인합니다. 하나라도 다르면 멈추고 보고합니다.
  - `chronos-forecasting: 2.3.2`
  - `CUDA 사용 가능 True`
  - `합성 데이터 지문: 일치(17개 시나리오)`
- `본 실행 Chronos-2 예측 파일`의 개수는 그대로 보고합니다(0개여도 멈추지 않습니다).

## 1. 스모크 (수 분 예상)
