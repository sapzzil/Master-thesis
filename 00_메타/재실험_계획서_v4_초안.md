## 0. 연구 질문

TSFM이 내놓는 **내일 로그수익률의 80% 예측구간**은 금융 데이터에서 믿을 만한가?

| | 질문 | 어디서 |
|---|---|---|
| RQ1 | 어떤 금융 특성이 세질 때 구간이 무너지는가 | 실험실(합성) |
| RQ2 | 실제 주식에서 TSFM은 기준 모형보다 나은가 | 현실(실제 주식). 실험실에서도 같은 비교를 서술용으로 보고 |
| RQ3 | 무너진 구간을 재학습 없이 80%로 되돌릴 수 있는가 | 실험실 + 현실 |
| 공통 | 위 답들이 과거 길이(한 달/1년)와 입력 형태(가격/수익률)에 따라 달라지는가 | 전부 |

실험실과 현실은 같은 절차로 진행합니다. 다른 건 데이터(합성/실제)뿐입니다.

## 1. 예측 문제 (공통)

| 항목 | 내용 |
|---|---|
| 대상 | 내일 로그수익률 rₜ₊₁ = ln(Pₜ₊₁/Pₜ) |
| 방식 | 매 거래일 과거 L일을 보고 내일 하루만 예측하고, 하루씩 밀어서 반복. 재학습 없음 |
| 과거 길이 L | 21일, 252일 |
| 입력 형태(TSFM만) | ① 로그수익률 ② 가격 그대로(전처리 없음). 가격 입력의 출력 분위수 q는 ln(q/Pₜ)로 바꿔 채점 |
| 출력 | 0.1~0.9 분위수. 80% 구간 = [q0.1, q0.9] |
| 에피소드 | 80일 = 준비 20일 + 채점 60일. **모든 지표는 채점 60일만으로 계산**(준비 20일은 보정기 기록 시작용) |
| 근거 | 80% 구간이면 평균 5일에 한 번 빗나가므로, 60일 채점이면 빗나감이 약 12회 쌓여 보정 효과를 검증할 수 있다 |

## 2. 실험실: 합성 데이터

### 2-1. 3가지 특성, 4축

| 축 | 바꾸는 것 | 고정 |
|---|---|---|
| ① 변동성 군집 | GARCH(1,1) 지속성 α+β (α:β = 1:9) | 무조건부 분산 |
| ② 두꺼운 꼬리 | Student-t 자유도 ν (√((ν−2)/ν) 스케일) | 분산 |
| ③ 국면 전환-빈도 | 2국면 전환확률. 평온/격변 지속일의 비율은 실측 중앙값으로 고정 | 격변/평온 변동비 = 실측 중앙값 |
| ④ 국면 전환-크기 | 격변/평온 변동비 | 지속일 = 실측 중앙값 |

국면 전환 축은 무조건부 평균 0, 분산이 목표값이 되도록 전체 스케일을 맞춥니다(v3와 같은 방식).

### 2-2. 단계 규칙 (규칙은 지금 고정하고, 숫자는 실제 10종목 추정치로 산출)

추정 방법: 10종목 각각 2015-01~2026-09 일별 로그수익률에 GARCH(1,1)-t와 2국면 마르코프 전환(평균·분산 전환)을 적합합니다.

| 단계 | 의미 | ① 군집 | ② 꼬리 | ③ 빈도 | ④ 크기 |
|---|---|---|---|---|---|
| L1 | 특성 없음, **4축 공통 1개** | α+β = 0 | 정규분포 | 전환 없음 | 변동비 1 |
| L2 | 중간 | L1과 L3의 α+β 중간 | L1과 L3의 **초과첨도** 중간에 해당하는 ν | L3 전환확률의 절반 | L1과 L3 변동비 중간 |
| L3 | 현실의 **가장 약한** 쪽 | 10종목 α+β 최솟값 | ν 최댓값 | 전환확률 최솟값(가장 느린 종목) | 변동비 최솟값 |
| L4 | 현실 중앙 | 중앙값 | 중앙값 | 중앙값 | 중앙값 |
| L5 | 현실의 **가장 센** 쪽 | 최댓값 | ν 최솟값 | **전환확률 최댓값의 2배**(현실 초과 스트레스) | 최댓값 |

- 일 변동(무조건부 표준편차): 10종목 일 변동의 **중앙값**(현재 6자산 기준 약 1.8%). 평균은 0
- 공통 난수(CRN): 계열 번호 s별 기본 난수를 모든 축·단계가 공유합니다. 코드 단계에서 4축 L1이 같은 데이터를 만드는지 점검합니다.
- 시나리오 **17개**(L1 1개 + 4축 × L2~L5) × 계열 **100개** × 에피소드 1개
- 계열 하나의 구성: 워밍업 200일 + 과거 252일 + 에피소드 80일
- 100개의 근거: 시나리오당 6,000회 채점이면 커버리지 오차가 약 ±1~2%p라, 실질 기준인 2%p 차이를 잡아낼 수 있다. 1,000개로 늘리면 오차는 약 1/3로 줄지만 계산은 10배가 된다
- **정답 기준선(실험실 전용, 해석용)**: 생성 과정을 알기 때문에 참 조건부 분포의 10·90% 분위를 계산할 수 있습니다. "모델 탓인지, 원래 예측이 어려운 상황인지"를 구분하는 기준선으로 씁니다(GPU 불필요).

## 5. 지표

- **주지표**: 80% 커버리지
- **보조**: 분위수 손실(9개 분위 평균, CRPS 근사), 구간 폭, Winkler 점수 IS₀.₂

## 6. 사후보정 (공통)

- **방법**: ACI-CQR. 폭으로 나눈 이탈 정도를 기록하고, 그 기록의 (1−αₜ) 분위만큼 여유를 붙입니다.
- **설정**: α = 0.20, γ = 0.05, αₜ ∈ [0.02, 0.50]
- **기록장 단위**: 종목·계열별, 에피소드별. 준비 20일로 기록을 시작하고 60일을 채점합니다.
- **대조군**: 평균 상대폭이 같아지도록 일괄 확대
- **명시할 점**: 보정은 매일 실제값을 쓰고, 대조군은 쓰지 않습니다.

## 7. 가설과 판정

| 가설 | 내용 | 비교 | 검정 |
|---|---|---|---|
| H1 | 군집이 세질수록 커버리지 하락 | 같은 계열 L5−L1, L5−L3 | Wilcoxon 부호순위(양측) |
| H2 | 꼬리가 두꺼워질수록 하락 | 〃 | 〃 |
| H3a | 전환이 잦을수록 하락 | 〃 | 〃 |
| H3b | 전환 충격이 클수록 하락 | 〃 | 〃 |
| H4 | 고강도(L4~L5)에서 축마다 결손이 다르다 | 같은 계열 4축 | Friedman → 축 쌍별 Wilcoxon |
| H5 | 보정 후 80% 복원 | 커버리지 90% 신뢰구간이 [0.77, 0.83] 안 | 클러스터 부트스트랩 |
| H6 | TSFM이 RW보다 분위수 손실이 작다 | 같은 날·종목 | 월 블록 t검정(양측). 실험실은 계열 단위 Wilcoxon(서술용) |

- **유의**: Holm 보정 후 p < 0.05. Holm 묶음 = 가설·비교별 (TSFM 4 × 조건 4 = 16개)
- **실질**: 커버리지는 2%p 이상, 분위수 손실은 RW 대비 2% 이상 개선일 때 "실질적으로 의미 있음". 유의하지만 기준 미만이면 "통계적으로는 유의하나 작음"
- **함께 보고**: 효과 크기 + 95% 신뢰구간
- **조건 규칙**: TSFM마다 4조건에서 각각 판정
  - 4조건 모두 성립 → "조건과 무관"
  - 일부만 성립 → "조건에 따라 다름"(어느 조건인지 명시)
  - 없음 → 미지지
- 시나리오·모델·조건을 골라서 보고하지 않습니다. 전체 표를 보고합니다.

## 11-1. 구현 세부 (코드 `04_실험코드/src_v4/`, 2026-10-14 사전 시험 완료 — 동결 대상)

**과제 만들기** (`tasks_v4.py`)
- 수익률 입력 = 대상일 직전 L개 수익률, 가격 입력 = 대상일 직전 L개 종가. 기준가격 Pₜ = 맥락의 마지막 종가. 대상일 수익률은 맥락에 들어가지 않습니다(코드에서 위치로 점검, 사전 시험에서 원자료로 독립 재계산해 300건씩 확인).
- 실제 주식: 2017-01-02 이후 **모든 거래일**을 예측합니다(종목당 2,381~2,443일, 총 24,132건). 종목별로 처음부터 80일씩 잘라 에피소드를 만들고, 끝에 80일이 안 되는 자투리는 주분석에서 뺍니다(연속 보정 보조분석에만 사용). 주분석 에피소드 295개(23,600건).
- 거래량 0인 날 제외(§2-3과 같은 규칙).

**합성 생성** (`01_generate_synthetic_v4.py`)
- 군집 축은 정규 충격의 GARCH(1,1), 꼬리 축은 분산이 일정한 i.i.d. t, 국면 축은 두 국면 모두 평균 0인 정규. 첫 국면은 정상분포에서 뽑습니다.
- 공통 난수: 계열 s마다 z, u, v, s0를 한 번 뽑아 모든 시나리오가 공유합니다. 네 축의 L1 모수로 만든 데이터가 L1과 같은지 실행할 때마다 점검합니다.
- 정답 기준선: 군집 = 실제 σₜ의 정규분위, 꼬리 = 스케일된 t분위, 국면 = 어제 국면을 알 때 오늘 국면 혼합정규의 분위.
- 생성 결과는 시나리오별 Σr·Σr² 지문(`synth_fingerprint_expected.json`)과 맞아야 예측을 시작합니다.

**모델** (`02_run_inference_v4.py`, `baselines_v4.py`)
- TSFM 호출은 준비작업 k03에서 PC로 확인한 방식 그대로입니다. 배치는 k03 값으로 시작하고, 메모리 부족이나 9,500MB 초과 시 절반으로 줄입니다(결과 값에는 영향 없음).
- Chronos-T5 샘플은 조건마다 고정 시드(20261013 + L + 가격여부)입니다.
- 가격 입력 출력 q는 ln(q/Pₜ)로 바꾸고, q ≤ 0이면 유한값이 아닌 예측으로 기록합니다.
- 분위수 교차는 오름차순 재정렬 후 채점하고, 교차 비율을 보고합니다(§4).
- RW = 과거 L개 수익률의 평균·표준편차(ddof=1) 정규분포.
- GARCH(1,1)-t: 상수평균, 수익률×100으로 매일 재추정합니다. 추정이 실패하거나 값이 비정상(분산≤0, ν≤2, 유한값 아님)이면 그날만 RW와 같은 정규분포로 대체하고, 대체 건수를 보고합니다.
- 유한값이 아닌 예측은 빗나감으로 셉니다. 손실 계산에서는 빼고, 보정 기록에도 넣지 않습니다.

**사후보정** (`03_score_calibrate_v4.py`)
- 점수 sₜ = max(lₜ−yₜ, yₜ−uₜ)/(uₜ−lₜ).
- 준비 20일은 점수만 기록합니다. 채점일에는 기록 n개 중 k = ⌈(n+1)(1−αₜ)⌉번째 작은 점수 × 폭만큼 양쪽을 넓힙니다(음수면 좁힘). k > n이면 최댓값을 씁니다. 그 뒤 αₜ를 갱신하고 그날 점수를 추가합니다.
- 대조군 배율 = 같은 묶음(합성: 모델·조건·시나리오, 실제: 모델·조건·10종목 전체) 채점일의 평균 보정폭 ÷ 평균 원래폭.
- 사전 시험: 참조 구현과 200회 일치. 일부러 좁힌 구간(원래 38%)이 평균 80.3%로 보정되는 것을 확인했습니다.

**검정** (`07_analysis_v4.py`)
- 계열별 커버리지 = 채점 60일 평균. H1~H3b는 같은 계열의 L5−L1, L5−L3 차이를 Wilcoxon(pratt, 차이는 소수 10자리 반올림)으로 검정합니다.
- H4 결손 = 0.80 − (L4·L5 커버리지 평균). 4축 Friedman 검정 후 축 쌍 6개를 Wilcoxon으로 비교합니다. Holm은 쌍마다 16개입니다. "축마다 다름"은 Holm 유의이면서 축 평균 결손의 최대−최소가 2%p 이상일 때입니다.
- H5 = 클러스터 부트스트랩 2,000회 백분위 90% CI(합성: 계열, 실제: 달력 월).
- H6 = 같은 종목·날짜의 손실 차이(TSFM − 같은 L의 RW)를 달력 월 평균으로 묶어 t검정합니다. 개선율 = 1 − ΣQL_TSFM/ΣQL_RW.
- 정답 기준선(oracle)은 서술용이며, 합성 예측 경로 점검에도 씁니다.
- 학습 데이터 누출 점검(보조) 구간: 공개 다음 달 1일 이후입니다. Chronos-T5 2024-04-01, Moirai-2.0 2025-09-01, TimesFM-2.5 2025-10-01, Chronos-2 2025-11-01.
