# 프로젝트 실행 규칙 (구조/경로 전용 — 주제·진행상태는 여기 안 넣음)

> 현재 연구주제·진행단계·다음할일은 이 파일이 아니라 `진행상황.md`를 참고하세요.
> `진행상황.md`가 유일한 현재상태 정보원입니다 (이 파일엔 중복 기재하지 않음).

## ⚠️ 메타문서 역할 분리 원칙 (2026-08-25 강화 — 한 번 어겨진 적 있음)

- **`진행상황.md`**: 현재 상태 요약만. 사건 하나당 **1~3줄 + "(상세: 결정로그.md 2026-XX-XX 항목
  참조)"**로 끝낼 것. 검증 과정·판정 근거·긴 표·전체 서사를 그대로 옮겨적지 말 것.
- **`결정로그.md`**: 전체 이력. 사건의 전체 서사·근거·과정·왜 그렇게 판단했는지는 전부 여기로.
  append 전용, 지우지 않음.
- 이 원칙은 세팅 초기부터 있었으나(`setup_prompt_and_instructions.md` 설계 원칙 1·2), 2026-08-25에
  한 세션이 `결정로그.md`를 갱신하지 않고 모든 상세 내용을 `진행상황.md`에 계속 누적한 사례가 있었음
  (사용자가 직접 발견). 재발 방지를 위해 이 섹션을 신설.
- **어떤 세션 형태로 열리든(로컬 Claude Code, 디바이스 연결 Cowork, claude.ai Chat) 매 세션 시작 시
  이 파일을 먼저 확인할 것.** claude.ai Projects 탭의 Custom Instructions에도 동일 원칙이 등록되어
  있어야 하며(아래 "Projects 지침 동기화" 참조), 이 파일과 지침 둘 다 어긋나 있으면 최신 날짜가 적힌
  쪽을 신뢰하고 다른 쪽을 갱신할 것.

## 세션 시작 규칙
- 새 세션은 반드시 이 `CLAUDE.md`(역할 분리 원칙)와 `진행상황.md`(현재 단계·주제)부터 읽을 것
- **작업이 중간에 끊겼던 경우에만** `재개_지시서.md`를 추가로 읽을 것
  (평소에는 볼 필요 없음. 진행 중이던 작업의 이어받기 지시만 담긴 임시 문서)
- 그다음 `03_최종취합/관련연구_초안.md` 확인 (4단계 이후부터 존재 — 산출물명 정확히 이것)
- 작업 시작 전 반드시 `git status`, `git remote -v`로 현재 git 연결 상태 확인
- (git 연결 안 돼있으면) `git init` → `gh repo create --private` → 원격 연결 먼저 진행
- 연결돼 있다면 `git pull`로 최신 상태 확인

## 세션 종료 규칙 (자동 갱신)
- `진행상황.md`(로컬 사본)를 이번 세션에서 바뀐 내용으로 **요약만** 수정할 것
  (예: 진행 단계, 다음 할 일, 새로 정해진 결정사항 — 위 "메타문서 역할 분리 원칙" 준수)
- 바뀐 내용의 **전체 서사·근거는 반드시 `결정로그.md`에 append**할 것 (날짜 + 무엇이 왜 바뀌었는지).
  진행상황.md만 고치고 결정로그.md를 빠뜨리는 것이 이 프로젝트에서 실제로 발생했던 문제이므로,
  세션 종료 전 이 두 파일이 같이 갱신됐는지 반드시 재확인할 것
- `git add . && git commit -m "설명" && git push`
- 주의: claude.ai Projects 탭의 `진행상황.md`(클라우드본)는 로컬 파일과 자동으로 동기화되지 않음 —
  로컬 `진행상황.md`가 바뀌었으면 Projects 지식에도 동일 내용으로 재업로드할 것(Cowork/Claude Code가
  Projects 쓰기 권한이 있는 세션이면 직접, 없으면 사용자에게 안내)

## Projects 지침(Custom Instructions) 동기화

claude.ai Projects 탭 설정의 Custom Instructions는 이 파일과 별도로 관리되며, **디바이스 연결이 없는
순수 Chat 세션에서는 이 CLAUDE.md 자체에 접근할 수 없으므로** 지침 쪽에도 핵심 원칙이 등록돼 있어야
컴퓨터·세션 종류와 무관하게 항상 적용된다. 지침에 들어가야 할 최소 문구:

```
진행상황.md는 현재 상태 요약만 유지하고(사건당 1~3줄), 사건의 전체 서사·근거·과정은
로컬 결정로그.md(append 전용)에만 기록합니다. 진행상황.md를 갱신할 때 결정로그.md
갱신을 빠뜨리지 마세요.
```

이 문구가 지침에 없다면 사용자에게 추가를 요청할 것 — Claude는 이 필드를 직접 쓸 수 없다
(Projects 도구는 지식 문서만 쓰기 가능, instructions 필드는 읽기 전용).
